# 3D generation sources

## Retained BGS sourcing preference

When new generation is selected and no provider is specified, the package's existing sourcing preference is **Hunyuan 3D → Tripo → Meshy**. This is a retained BGS preference, not a ranking guaranteed by 3D-production standards or provider capability. Select an available authorized route that delivers the required result; the list does not authorize paid comparisons or require trying every provider. Suitable supplied assets and explicit user choices retain priority. Provider capabilities, entitlements and rights follow the current official source/account.

## 1. Hunyuan 3D / 混元3D

- [Official web application](https://3d.hunyuan.tencent.com/): use the authorized browser session and the options actually offered to that account.
- [Tencent Cloud API overview](https://cloud.tencent.cn/document/product/1804/120838): submission/query interfaces cover model generation and related texture, topology, UV and rigging operations. Choose only operations the current asset needs; use an existing configured client or integration, not invented BGS adapters or keys in project files.
- [Official Hunyuan3D-2.1 repository](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1) and [version-specific license](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1/blob/main/LICENSE): relevant when a local/open-source installation is actually selected. Its license does not describe hosted account entitlements. Source preference alone does not authorize installing model weights or a new service.

For the chosen hosted/API route, resolve its actual output formats, texture/export support, applicable usage terms and authorized charge before submission. Do not assume the web app, Cloud API and local model share accounts, credits or licenses.

## 2. Tripo

- [Studio](https://studio.tripo3d.ai/), [API documentation](https://developers.tripo3d.ai/), [commercial-use guidance](https://www.tripo3d.ai/help/privacy-policy/how-to-use-tripo-models-commercially).
- The linked guidance distinguishes free and paid output rights; confirm the rights applicable to the model's generation account and intended use. A reference image still needs its own permitted use.

## 3. Meshy

- [Application](https://www.meshy.ai/), [API documentation](https://docs.meshy.ai/), [free-plan/export details](https://help.meshy.ai/en/articles/15696428-what-is-included-on-the-free-plan).
- The free-plan page checked 2026-11-03 limits ordinary free downloads to untextured Meshy 6 Lite models; generation credits do not unlock textured downloads. Confirm actual export availability before depending on a textured delivery. That page describes CC BY 4.0 attribution conditions for free-plan outputs; retain the applicable license with the resource.

## Retain only relevant source facts

Reuse valid information already known for the account/source. Resolve changed or unknown entitlements, permission, rights and price through current official information and the authorized account; do not copy a full account dossier or repeat screenshots for every asset. Retain task/source identity, applicable rights/attribution, actual charges and downloaded file provenance in existing resource records when available. Submit through an authorized supported interface; login, CAPTCHA and unavailable exports may require user action rather than retries.
