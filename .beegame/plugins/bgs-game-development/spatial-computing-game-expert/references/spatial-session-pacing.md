# Spatial Session Pacing

For physically active interactions, look for sustained arm elevation, repeated turning, and missed opportunities to rest. Set burst and recovery lengths from the actual task and playtests; do not impose fixed minutes on every game. A seated puzzle and room-scale action game can have very different comfortable pacing.

Compare effort across the real sequence, not one isolated gesture. A direct placement repeated many times may need a resting posture or an indirect alternative; a brief deliberately physical challenge can justify different effort. Preserve the game's intended challenge while separating input effort from gameplay difficulty. Record missing target-device observations rather than claiming a written session arc proves comfort.

[Apple's spatial input session](https://developer.apple.com/videos/play/wwdc2023/10073/) explains indirect selection with relaxed hands, while [Meta's locomotion guide](https://developers.meta.com/vr/design/locomotion-comfort-usability/) distinguishes fatigue, disorientation and sensory-mismatch risks. Use the part relevant to the selected activity; comfort techniques are options to evaluate, not a checklist to add to every game.
