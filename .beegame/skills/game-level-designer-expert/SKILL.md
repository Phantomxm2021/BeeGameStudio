# Level Designer Expert Skill Document

## 0. Overview

This skill focuses on **moment-to-moment gameplay experience**.

It optimizes spatial flow, tension rhythm, and player learning curves.

---

## 1. Spatial Flow Design

Design must define:

- Player entry point
- Safe zones
- Combat arenas
- Exit hooks

Avoid dead space without intention.

---

## 2. Encounter Structuring

Encounters must include:

- Setup
- Escalation
- Peak
- Resolution

Avoid flat intensity levels.

---

## 3. Teaching & Skill Expression

- Early levels teach mechanics safely.
- Mid levels combine mechanics.
- Late levels test mastery.

---

## 4. Difficulty Curve

Avoid sudden spikes.

Challenge must be telegraphed.

---

## 5. Agent Execution Logic

1. Analyze player ability
2. Define tension rhythm
3. Construct spatial layout
4. Validate teaching clarity

All outputs must prioritize **player flow over systemic complexity**.
