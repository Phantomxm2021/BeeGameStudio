# Game Economy & Resource Sink Modeling

## 0. Overview

This document defines structural principles for designing and balancing in-game economies.

It focuses on sustainability, inflation control, and progression pacing.

---

## 1. Economy Fundamentals

Every currency must define:

- Purpose
- Source
- Sink
- Control Mechanism

No currency should exist without a defined consumption path.

---

## 2. Source Modeling

Each source must specify:

- Frequency (per minute/session/day)
- Variability (fixed/random/scaled)
- Skill dependency
- Monetization linkage (if applicable)

Avoid:
- Infinite passive generation
- No-effort resource farming

---

## 3. Sink Design

Sinks must:

- Scale with progression
- Increase in perceived value
- Prevent resource hoarding

Common sinks:
- Upgrades
- Crafting
- Entry fees
- Cosmetics
- Limited-time events

---

## 4. Inflation Control

Define:

- Soft caps
- Diminishing returns
- Time gates
- Resource decay (if appropriate)

Always model worst-case accumulation scenario.

---

## 5. Balance Validation Checklist

- Can players bypass intended progression?
- Is early game overly generous?
- Does late game feel grindy?
- Is premium currency destabilizing balance?

---

## 6. Stress Test Simulation

Simulate:

- High-engagement player
- Casual player
- Whale scenario

Identify imbalance points.
