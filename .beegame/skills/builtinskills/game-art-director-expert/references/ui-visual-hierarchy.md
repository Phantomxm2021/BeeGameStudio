# UI Visual Hierarchy

At the player's normal viewing size, distinguish the immediate action, urgent state, supporting information, and decoration. Use typography, value, spacing, shape, and motion as needed; not every layer requires a different font or contrast tier.

Keep visual language coherent with the game world while preserving legibility and interactive affordances. Verify expanded text, varying aspect ratios, and the intended input device. For behavior, focus, and layout details, use the game UI/UX Skill rather than turning art direction into a second UI specification.
