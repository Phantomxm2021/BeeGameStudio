# UI Visual Hierarchy System

## Purpose
Define UI structure clarity and visual priority.

---

## 1. Hierarchy Layers

1. Critical Information (HP, Timer)
2. Actionable UI (Buttons)
3. Secondary Data
4. Decorative Elements

Each layer must have distinct size + contrast tier.

---

## 2. Typography Rules

Define:

- Font family
- Max font types (≤ 2)
- Title scale multiplier
- Numeric emphasis style

Avoid inconsistent scaling.

---

## 3. Animation Language

- Party style → Bounce / Elastic
- Competitive → Sharp / Linear
- Minimal → Fade / Slide

Animation must match world tone.

---

## 4. Density Control

Mobile:
- Large tap targets
- Minimal clutter

PC:
- Higher info density allowed

XR:
- Depth-layered UI
- Avoid flat overlays
