# Shape Language Framework

## Purpose
Define geometric philosophy across characters, props, UI, and environment.

---

## 1. Core Geometry Philosophy

Choose dominant base:

- Round → Friendly / Soft / Party
- Square → Stable / Order
- Triangle → Aggressive / Fast
- Asymmetry → Chaos

All assets must inherit from the same base logic.

---

## 2. Proportion System

Define:

- Head-to-body ratio
- Limb exaggeration level
- Object thickness style
- Silhouette readability rule

Silhouette must be recognizable at 50% scale.

---

## 3. Gameplay Clarity Rule

- Dangerous objects → Sharp / angular
- Safe objects → Rounded
- Interactive elements → Visually protruding

No ambiguous silhouettes.

---

## 4. Consistency Constraint

If world is round-dominant:
- Avoid mixing heavy sharp language
- Use contrast only for gameplay signals
