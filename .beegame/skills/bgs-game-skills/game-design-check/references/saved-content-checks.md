# Saved Content Checks

Read only for an assigned geometry/integration question using these actual inputs, or a supplied legacy handoff. This reference preserves format-specific details without making them a default design-review workflow. Native engine or DOM tasks use their actual source and runtime, not BGS JSON created for a checker.

For current BGS source reads, use ReadDesignHandoff `{}` for file availability, `{read:[{document:"GDD.md"}]}` for one document’s headings, and `{read:[{document:"GDD.md",sections:["Exact heading"]}]}` for original clauses. ReadImplementationTask `{}` or `{"id":"actual-id"}` reads the existing task directory or task/owner section locations without locking. CheckResourcesAndBindings `{}` checks actual registered files and saved UI/Scene references; `detailsFor` expands one file without narrowing checks. ReadVerificationResults reads existing results/freshness without running checks. These tools do not certify semantics or runtime quality; use BGS file-reading tools for additional sources and pictures.

## Linked Scene/UI geometry

Use current saved owner-linked content and the current supplied check entry; resolve its actual path from the active task and read `--help`. `--check-drafts`, `--layout-draft`, `--design-layouts` and `--scene-layouts` answer different saved-source questions. Source coverage and agreement with prose still require inspecting the actual design. A linked Scene's identities, hierarchy, placement, collision and Camera must agree with the space requirements. Scene schema/Camera checks and visibility in the UI's actual allocated game-view establish different properties. Missing resource-dependent bounds or unsupported dynamic/3D/XR framing need a disclosed needed-by check, not guessed dimensions or semantic PASS.

For an assigned BGS UI geometry check, use the actual linked files and the applicable [layout calculation guidance](../../game-ui-ux-designer/references/layout-calculation.md) for fields, projection, coexisting-layer links and calculator usage. Reuse that guidance if already loaded; do not maintain a second layout contract here. Continue the same files into integration, not a separate test composition.

Compare screen/expanded-state coverage, active nodes, supported targets and clearance policy with both global and state-specific prose. Disabled content is not an inspected expanded state; independently fitting files or a permitted data policy do not prove agreement. Missing links/markers provide no combined clearance evidence. A geometry pass does not prove complete resources or runtime consumption. For new work, actual visual design selection and corresponding resource preparation precede UI/Scene JSON; do not create missing layouts merely to run this checker.

In authorized revision, correct the same sources and affected prose, then recalculate invalidated checks. Binding completion is not permission to change geometry. Preserve agreed control minima and required content; the calculator does not select an overlay policy or certify text fit, appearance or interaction. Reuse valid diagnostics rather than rerunning unchanged inputs. Sample screenshots and matching numbers do not substitute for the actual calculation.

## Only when legacy handoff inputs are supplied

Handoff indexes point to authoritative prose and necessary acceptance expectations, not duplicate design. Use results for the inspected versions and the commands actually supplied for that legacy assignment. The current autonomous tools do not require a batch handoff or release sequence. Do not create indexes, batches, delivery files or receipts merely to invoke an old command.

Preserve existing version/hash metadata. Inspect actual producer/consumer meaning and source conditions; neither matching IDs/headings nor different professional names establishes semantic agreement/conflict. A retained hash binds the declared source identity, not truth. Do not populate irrelevant tables or infer platform absence from a tool-scope rejection. A structural correction repairs a real contract violation without selecting a missing owner decision.
