## 1. 方向一句话

**「霓虹街机夜」**：深夜蓝紫底色上的发光霓虹竞技场——经典街机打砖块的现代风格化演绎：干净、明亮、带轻微合成波（synthwave）气质，但以可读性为第一原则，不做复古像素。

情绪关键词：专注、明快、带电的兴奋感；一局只有几分钟，视觉始终"提神"而非"压迫"。

## 2. 形状语言

- 通用语言：**圆角矩形 + 胶囊形 + 正圆**，统一较大圆角（砖块圆角半径 4–6，挡板全圆角胶囊，按钮圆角 10–14）。
- 砖块：家族化的圆角矩形，区别仅在颜色亮度与内部标记；2 命砖带**内嵌描边边框 + 表面两条短横杠**（明确"更坚固"的语义）。
- 挡板：横向胶囊，两端比中部略亮，暗示"两端反弹更偏"。
- 球：带辉光的正圆，是全画面最亮的物体，任意背景上都最先被看见。
- 墙：不用实体墙块，而以**细霓虹边线**表达（顶/左/右各一条 2–3px 发光线），保持视觉轻盈。

## 3. 调色板

| 角色 | 颜色（参考值） | 用途 |
|---|---|---|
| 背景深底 | `#12102A` → `#1E1B45`（垂直渐变） | 场地底色 |
| 背景网格线 | `#2C2860`（低透明度） | 远景透视网格，仅装饰 |
| 1 命砖 | 青色族 `#29D3E0` / 行向微调到 `#46B8FF` | 下 4 行 |
| 2 命砖 | 品红–紫族 `#E357C9` → `#9A5CFF` | 上 2 行 |
| 挡板 | 青柠白 `#D8FFE0` 带 `#5CFFB0` 辉光 | 玩家实体 |
| 球 | 近白 `#FFFFFF` 带 `#9FFCF0` 外辉光 | 核心焦点 |
| 危险/失命反馈 | 暖橙红 `#FF7A5C` | 仅用于出底闪示、生命扣除 |
| UI 主文字 | `#F4F2FF`；次要文字 `#9E9AC8` | HUD 与界面 |

- 砖块行之间允许同色相轻微明度递进（下亮上深），形成阵列的层次节奏，但 1 命/2 命两大色族必须一眼可分。
- 留边区（letterbox 多出的空间）由背景渐变与网格自然延伸填充，不出现纯黑边。

## 4. 层级与构图

从后往前四个独立层，支持分层运动/透明与宽高比延伸：

1. **背景层（最底）**：垂直渐变 + 极淡的合成波透视线/点阵；可在垂直方向微幅滚动，但静止时也成立。向所有留边区延伸。
2. **墙线层**：三条霓虹边界线与底部一条**虚线警示边**（提示死亡边的存在，是重要的可教信息）。
3. **游戏层**：砖块、挡板、球；本层承载全部玩法读性。
4. **前景层（最顶）**：轻微暗角（vignette）、碎砖粒子与辉光、失命时的边缘暖闪。不允许任何持久性遮挡。

- 辉光统一使用外发光（软、半径小），全画面发光强度克制：球 > 挡板 > 砖块，避免亮成一团。
- 碎砖反馈：小块同色碎屑迸溅（8–12 粒，0.3–0.5s 衰减）+ 一次短促辉光脉冲；2 命砖首次被击中时不碎裂，表现为**整体亮度闪白一拍并出现一条裂纹**（状态变化可辨）。

## 5. 玩家如何区分各类信息（不只靠颜色）

| 信息 | 颜色 | 形状/标记/运动冗余 |
|---|---|---|
| 挡板（玩家） | 青柠辉光 | 唯一胶囊形、最底部运动实体 |
| 球 | 白青辉光 | 唯一正圆、全画面最亮、持续运动 |
| 1 命砖 | 青蓝 | 纯色填充圆角块 |
| 2 命砖 | 品红紫 | **内嵌描边 + 两条表面横杠**；受损后出现裂纹 |
| 墙/边界 | 冷色线 | 连续霓虹线；死亡边为**虚线 + 偶尔的暖色脉冲**，与反弹墙明确区分 |
| 失命/危险 | 橙红（全画面唯一暖色） | 边缘闪 + 球消失动画 |
| 生命显示 | UI | 心形/挡板形图标，扣除时图标消失并轻抖 |

- 色盲情形下：1 命砖（实心）与 2 命砖（描边+横杠）、反弹墙（实线）与死亡边（虚线）均有形状冗余；危险色是场景中唯一暖色。

## 6. 屏幕界面的视觉身份（不只是世界资产）

- **开始界面**：居中大字标题「打砖块」，粗重几何无衬线 + 轻微霓虹描边/外发光；标题下方一个小型主题图形——**挡板托球**的胶囊+圆球徽标，点明全部玩法。底部一颗发光胶囊按钮「开始游戏」。背景比游戏中更安静（网格更淡、暗角更深），视线只落在标题与徽标上。
- **HUD**：左上分数（大号数字等宽对齐），右上暂停（44×44 图标按钮），生命以挡板/心形小图标排在分数旁；顶部 HUD 带半透明深色底，不侵入砖区。
- **暂停层**：整屏 60–70% 深色压暗 + 居中窄面板（霓虹描边圆角板），世界仍隐约可见，表达"时间冻结而非离开"。
- **结算（胜利/失败）**：胜利——青色系明亮脉冲 +「通关」与总分；失败——暖红压低亮度 +「游戏结束」；两者共用居中面板结构与「再玩一次 / 返回开始」两颗按钮，情绪由光色区分。
- 转场情绪：失命是短促暖色下沉闪；进入结算面板用 0.2–0.3s 轻微缩放+淡入，干脆不拖沓。

## 7. 字体与动态特征

- 字体：粗几何无衬线中文字族（系统回退：`"PingFang SC", "Microsoft YaHei", system-ui, sans-serif`，标题用更重字重 + 字间距收紧）；数字用等宽数字字形，保证分数跳动不抖动。
- 动态：球与挡板的运动本身不加拖影（保证位置判断准确）；辉光与碎屑提供运动能量感。UI 动效短而脆（150–300ms），无弹跳卖萌。

## 8. 一致性标准（适用于生成/检索/程序化资产）

1. 所有圆角矩形资产遵循同一圆角与描边粗细规范；发光方向、色温符合 §3 色表。
2. 2D 资产按设计坐标尺度产出：砖块 80×24、挡板 120×16、球可视直径约 16（辉光除外），不得在资产内自带与世界冲突的尺度。
3. 不使用写实纹理、渐变拟物、像素风描边；允许噪点/颗粒，但密度低于"远观能察觉"。
4. 不同来源资产须通过：剪影归类测试（缩小到 64px 高仍能分出砖/挡板/球）、色族测试、发光一致性测试。
5. UI 与世界共用同一霓虹/圆角语言与色表，UI 不另立材质风格。
