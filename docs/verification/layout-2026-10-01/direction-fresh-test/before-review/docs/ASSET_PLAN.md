## 1. 总体采购结论

**首版无需任何外部位图、字体或音频文件**：全部视觉以 Canvas 2D 矢量程序化绘制、界面以形状+系统字体呈现、全部声音以 WebAudio 程序化合成。

依据（非"因为便宜"）：
- 美术方向的构成要素是圆角矩形、胶囊、正圆、细发光线与纯色碎屑——均为运行时活几何，格式约定明确"简单的实时几何不需要烘焙成纹理"。
- 视觉要求里唯一可能昂贵的是外发光；若实测成为性能瓶颈，回退方案是一张预渲染发光贴图（§6），而非放弃发光规则。
- 电子音色（振荡器+短噪声）天然匹配"合成波/芯片音乐"方向，且消除素材来源与授权风险。

因此 `assets/asset-manifest.json` 首版保持空清单，Scene/UI 文档 `assetRefs` 均为空（现状一致）；content/index 无需新增资源引用。

## 2. 视觉资源规格（程序化绘制族）

绘制顺序与层级遵循 ART_DIRECTION §4；坐标以场景文档 §3 为权威；颜色取 ART §3 色表。所有发光用 canvas `shadowBlur/shadowColor`，发光强度序：球 > 挡板 > 砖。

### 2.1 背景层 `proc-background`

| 项 | 规格 |
|---|---|
| 消费方 | worldCanvas，所有状态（开始界面时网格更淡、暗角更深） |
| 内容 | 垂直渐变 `#12102A→#1E1B45`；低透明度合成波透视线/点阵（线色 `#2C2860`），可垂直微滚 |
| 尺寸/延伸 | 绘制面覆盖**全宿主容器**而非仅 960×540 参考视图：letterbox 留边区同样绘制渐变与网格，保证无黑边（关卡 §4、UI §9） |
| 透明/层 | 最底层，不透明 |
| 变体 | 开始/结算界面：网格透明度降低；无其他状态变体 |

### 2.2 墙线与死亡边 `proc-walls`

- 消费方：进行中/发球准备。
- 顶/左/右：2–3px 冷色霓虹实线（`#3A3580` 加青辉光），沿世界边界。
- 底部死亡边：**虚线**（等长划空，约 8–10px 划）+ 偶发暖色脉冲；与实线墙的形状差异是关键可教信息（ART §5）。
- 仅沿参考视图世界边绘制（不随留边区外移——世界边界不变）。

### 2.3 砖块族 `proc-brick`（4 个绘制变体，0 外部文件）

逻辑尺寸 80×24，圆角 4–6，中心 pivot。变体由运行时按节点 behavior 的 hp 与受损状态选择：

| 帧/变体 | 触发状态 | 绘制规格 |
|---|---|---|
| `brick-hp1` | 1 命砖在场 | 纯色填充（青蓝族，按行做允许的明度递进）+ 轻外发光 |
| `brick-hp2-full` | 2 命砖未被击中 | 品红紫填充 + **内嵌描边 + 表面两条短横杠** |
| `brick-hp2-damaged` | 2 命砖剩 1 命 | 同上 + 一条裂纹 + 被击中瞬间整砖闪白一拍 |
| `brick-breaking`（一次性反馈） | hp 归零当帧 | 砖块消失 + 同色碎屑 8–12 粒（0.3–0.5s 衰减）+ 辉光脉冲 |

- 排布（60 块、位置公式、r0–3/r4–5 配比）由场景 JSON 节点数据决定，绘制器不持有位置副本。
- 不做九切片（砖块为独立小面，无拉伸）；无 tilemap 需求。

### 2.4 挡板 `proc-paddle`

- 120×16 全圆角胶囊，`#D8FFE0` 填充、`#5CFFB0` 辉光；两端略亮暗示大偏转；中心 pivot。
- 状态：默认；受击瞬间允许 1 帧极轻压缩反馈（不改变碰撞盒观感即可，不新增玩法）。

### 2.5 球 `proc-ball`

- 可视直径 16（r=8），`#FFFFFF` + `#9FFCF0` 外辉光；全画面最亮；无拖影（保证位置判断，ART §7）。
- 吸附态（发球准备）：跟随挡板绘制在其顶面中心。

### 2.6 粒子 `proc-particles`

- 运行时生成的简单矩形/圆点碎屑，单次碎裂上限 12 粒；参数驱动，不烘焙纹理。

## 3. UI 视觉资源

全部以 UI JSON 已声明的形状/文字节点成立（content/ui 现状），**不需要额外美术资产**：

- 徽标（开始界面焦点图形）：球（26 圆）+ 挡板（88×14 胶囊）两个形状节点，承担 ART §6 的"挡板托球"主题图形。
- 图标：暂停（文字「II」）、静音（文字/字符，44×44）；加载指示（青色圆，旋转为程序动效，reduced-motion 静止）。
- 面板：半透明深底 + 霓虹描边，按 style 字段绘制，无九切片图。
- 字体：系统粗几何无衬线（ART §7 回退链），不加载字体文件；数字等宽。
- 若评审认为字符图标语义不足，唯一允许增补的是**一枚小型 UI 图标帧组**（暂停/静音/继续，建议同一组程序化生成 PNG，44×44/帧、透明背景），届时再登记资源；当前不预先生产。

## 4. 音频资源规格（WebAudio 合成族）

行为权威为 AUDIO_DESIGN（触发、时长、优先级、电平）；以下为"制作配方"，产出无需音频文件。

| 事件 | 合成配方（性格） | 关键参数 |
|---|---|---|
| sfx-paddle | 正弦/三角短促弹音，音高随击球点偏移 | 基频范围约 300–600Hz（中点→边缘映射），0.08–0.12s 快速衰减 |
| sfx-wall | 高频方波/窄脉冲轻击 | 约 800–1200Hz，0.05–0.08s |
| sfx-brick-break | 短噪声爆裂 + 上扬正弦尾 | 0.12–0.18s，带高通噪声粒 |
| sfx-brick-hit | 闷中频三角波 | 比 break 低约 300–400Hz 亮度，0.08–0.1s |
| sfx-serve | 双频快速上扬 | 0.1s |
| sfx-life-lost | 下滑正弦 + 低通噪声尾 | 约 500→120Hz，0.5–0.7s |
| sfx-win / sfx-lose | 程序琶音（明亮上行 / 低沉下行 2–3 音） | 1.0–1.5s / 1.2–1.6s |
| sfx-ui | 极短方波确认 | 0.04–0.06s，80ms 内重启复用 |
| music | 音序器循环：合成波贝斯 + 琶音 + 简单节拍 | 60–90s 无缝循环；−12dB；首次手势后启动 |

- 主控限幅；混音并发规则（同批碎砖只发一次、同帧优先级）在音频模块按 AUDIO §4 实现。
- 合成器在首次手势时初始化 AudioContext；被自动播放策略拦截时静默降级（AUDIO §6）。

## 5. 必需 vs 可选

| 类别 | 必需（首版） | 可选增强（不做） |
|---|---|---|
| 视觉 | §2 全部程序绘制族 + §3 形状 UI | 自定义图标 PNG 组、自定义字体、正式美术封面图 |
| 音频 | §4 全部合成事件 + 音乐循环 + 静音 | 外部音乐曲目、双音量持久化、多层采样 |
| 注册资源 | 无（manifest 空） | — |

每项均有明确设计用途，无装饰性资产、无封面图需求；开始/结算界面的视觉身份由形状与光色承担（ART §6）。

## 6. 生产与可用性要求、回退方案

| 风险/条件 | 判定"可用"的标准 | 回退（不改设计规则） |
|---|---|---|
| Canvas 发光在低端设备掉帧 | 目标视口下稳定 60fps（技术 §7 预算） | 预渲染一张发光贴图（球/砖/挡板辉光各一帧，小图集，透明 PNG），以 blit 替代 shadowBlur；仅此情形引入位图并登记 manifest |
| WebAudio 合成音乐听感单薄 | 评审实听确认"通电街机"氛围成立 | 检索/生成 1 条 CC0 合成波循环（60–90s 无缝，授权清晰），SFX 保持合成 |
| 系统字体标题不达预期 | 标题字形粗重、霓虹处理后身份明确 | 仅标题改用一份授权清晰的开源中文字重子集（注册为字体资源） |
| 外部回退资产的来源 | 授权可商用、风格通过 ART §8 一致性测试（剪影/色族/发光） | 来源不符则继续使用程序化版本，不以"通用控件/通用素材"顶替既定视觉处理 |

## 7. 装载寿命与分组

- 无启动图集（无位图）；首屏零外部媒体请求，仅加载 content 文档本身。
- 若启用 §6 任一回退：发光小图与游戏场景同寿命（startup 必需）；外部音乐按 on-demand 在首次开始游戏时装载；不与无关内容混合打包。
- 字体子集（如启用）随 startup 加载。
