## 1. 数值设计目标

- **公平**：每次失命都给过可达成的救球窗口；失误源于位置/角度判断而非速度不可追。
- **张力**：挡板键盘移动速度略慢于球的最快水平速度，迫使玩家预判而非临场追球；鼠标/触控 1:1 映射则保证直接操控的精准。
- **掌握表达**：回球角度完全由击球点决定，高手能用连续边角球快速清空顶部 2 命区。
- 无经济、无成长曲线、无跨局持久化，本文件不引入任何此类系统。

单位均为设计逻辑像素与秒（世界 960×540，见关卡文档 §2）。

## 3. 派生规则与可达状态

### 3.1 挡板击球角度公式

设击球瞬间接触点相对挡板中心的水平偏移为 `dx`，挡板半宽 `P = 60`：

```
t = clamp(dx / 60, −1, +1)
θ = t · 60°                       （θ 为出射方向相对垂直向上的偏角，t>0 向右）
vx = ballSpeed · sin(θ)           范围 [−363.7, +363.7] px/s
vy = −ballSpeed · cos(θ)          范围 [−420, −210] px/s（向上为负）
```

- 可达到的垂直速度分量最小值 = 420·cos60° = **210 px/s**；水平分量最大值 = 420·sin60° ≈ **363.7 px/s**。
- 该 60° 上限同时是"防近水平"钳制：即使球击中挡板最边缘，也保证明确的垂直分量，杜绝球在墙间长时间横飞。
- 角度映射只在球自上方击中挡板顶面时适用；发球后的初始运动不受其影响。

### 3.2 出底与计分派生量

- 单局理论满分 = 40×50 + 20×100 = **4000 分**。
- 击碎砖块的最少击球次数 = 40×1 + 20×2 = **80 次命中**。
- 球整体越过底边判出底：球心 y − 8 > 540，即球心 y > 548（与关卡文档一致）。

## 4. 关键数值的可复现推演

### 4.1 下行救球窗口（核心公平性检查）

情境：球在砖区下沿（y=244）开始向下运动，挡板位于 y=500，纵向距离 256px。

- 垂直下行速度在 [210, 420] 之间：
  - 最陡（接近垂直，420）：到达挡板线时间 = 256/420 ≈ **0.61 s**。
  - 最斜（θ=60°，210）：256/210 ≈ **1.22 s**。
- 若预测落点偏离挡板中心 200px：
  - 键盘横移 200px 需 200/600 ≈ **0.33 s** < 最陡窗口 0.61 s → 可救。
  - 偏移 420px（从一端到另一端附近）需 0.70 s：在最陡球路下来不及——但最陡球路意味着球接近垂直、落点接近其当前 x，玩家应提前站位；这是"预判"压力的来源，不是不公平的瞬发死亡。
  - 鼠标/触控为 1:1 映射，一次横向划动即可到位，窗口始终充裕。
- **支持的结论**：在"正常站位、偏差一个身位量级"的情形下救球窗口成立；极端错位 + 陡峭下落属于可预见的失误代价。该结论不覆盖所有局面的数学证明。

### 4.2 全竖向行程与交战节奏

- 挡板线（500）到顶墙（0）距离 500px：垂直球往返一次约 2×500/420 ≈ **2.38 s**。
- 斜向球（vy=210）单程最长 500/210 ≈ **2.38 s**，单次回球间的观察时间不会被拉长到无聊。
- 发球点 (480,484) 到砖区下沿 (244)：240/420 ≈ **0.57 s**，发球后半秒多即进入首次碎砖反馈，开局不空转。

### 4.3 输入方式的平衡关系

- 键盘：速度 600 < 球最大水平速度 363.7? 否（600 > 363.7），单看速度追得上；但球从砖区到底部最短 0.61s 内键盘最大横移 366px，故远端突变球路仍需预判。
- 指针：位置映射无延迟，精度优势对应"需要按住/持续在画面上操作"的成本；两者无输入上的数值碾压，差异主要在手感，待实机对比（§6）。

## 5. 初始值为何适合目标体验

- 420 px/s 的球速使纵向循环落在约 2.4s 量级——街机式快节奏，但单次碎砖反馈（0.57s 到达）足够即时。
- 3 条生命 × 80 次必需命中：容许若干失误，同时让"零失误通关"成为可追求的掌握目标；无道具/无变速，难度完全来自固定布局与角度控制，符合最小可完整体验。
- 50/100 两档分值与砖块 hp 成正比（每点命中价值 50 分），计分可心算、反馈清晰，不制造额外系统。

## 6. 平衡风险与待实测假设

| 项 | 类别 | 说明 / 验证方式 |
|---|---|---|
| 球穿透薄砖 | **可行性风险** | 60fps 下球每帧移动 7px，小于球直径 16 与砖高 24；常规离散碰撞应安全，但高速贴砖角仍可能漏检。技术设计采用扫掠/连续接触检测；实机验证四角与砖缝情形。 |
| 垂直发球导致竖直往返闭环 | 调校假设 | 对称布局下理论存在球沿 x=480 永久竖直弹跳的局面；玩家可在挡板接触瞬间微移破除，概率低。若实测常见，改为发球带固定 ±15° 初始偏角（属数值微调，不改规则）。 |
| 键盘与指针的难度差距 | 调校假设 | 420/600 的速度配比未经真人测试；首轮游玩后按失命分布在 [360–480]（球速）、[500–720]（键盘速度）区间微调。 |
| 2 命砖区节奏 | 调校假设 | 顶部 20 块 2 命砖显著增加回合数，是否构成尾段拖沓需实测；备选是将上 2 行减为 1 行（空间+数值同步修订）。 |
| 60° 偏转手感 | 调校假设 | 数学范围合理但角度—位置曲线的线性度手感待验证；保持钳制机制不变、仅调角度上限。 |

- 表中"调校假设"均为发布后依据游玩测试修订的对象，不阻塞首版制作；不存在悬而未决的产品决策。
- 所有时长均为**几何计算结果**，未进行运行时或真人游玩验证。
