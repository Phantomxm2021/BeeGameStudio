## 1. 视觉方向（一句话执行标准）

> **夜色棋盘上的一台精密街机：冷静、近乎安静的深色网格，承载一条轮廓清晰、动作干脆的绿色蛇；唯一的暖色食物是全场焦点；墙是坚硬的框，UI 是悬浮在棋盘上方的发光标牌。**

判断任何一个视觉决策是否成立，用以下四条可执行标准，而不是"好看/有风格"：

1. **一眼分级**：正常游戏画面中，视线顺序必须是 食物 → 蛇头 → 蛇身 → 墙 → 棋盘底纹。
2. **去色仍可玩**：转成灰度后，仍能凭形状与轮廓分清蛇头、蛇身、食物、墙。
3. **缩到手机仍成立**：每格约 19px 的竖屏实机上，蛇头朝向与食物位置不得丢失。
4. **静得下来、响得到位**：背景与常态材质安静不闪烁；只有吃食物、死亡、破纪录三类事件允许强烈动效。

情绪基调：专注、轻巧、略带街机电光感；不做暗黑恐怖，也不做糖果卡通。

## 2. 形状语言

| 角色 | 形状 | 边角处理 | 轮廓 |
|---|---|---|---|
| 蛇头 | 圆角方块，前端略宽（梯形暗示），占整格约 90% | 圆角半径 8/32 | 深色实描边 |
| 蛇身 | 圆角方块（或相邻节以圆角连成带状，见未决项），占整格约 80–84% | 圆角半径 7/32 | 深色实描边 |
| 食物 | 菱形（45° 方形）内嵌圆形高光，整体在格内旋转 45°，占格约 70% | 尖角，与蛇的圆角构成对立 | 自发光而非描边 |
| 墙 | 直线条、硬转角的框体，四角为直角或斜切 | **零圆角**，与蛇形成"软 vs 硬" | 顶部一条亮边 + 内侧投影 |
| UI 面板 | 圆角矩形卡片，圆角半径统一（具体值归 UI_UX_SPEC） | 与蛇同一圆角家族 | 细发光边 |

统一规则：

- **圆角属于"活物/界面"（蛇、按钮、卡片），直角与尖角属于"环境/危险/奖励"（墙、食物）。** 食物虽非危险，但用尖角换取对蛇身的最高可辨识性。
- 所有元素对齐 32px 网格，描边宽度在设计坐标下取 2px（外层暗描边），不允许元素各用各的线宽。
- 不写实质感（无鳞片纹理、无木纹砖墙），形状本身即识别。

## 3. 调色板（具体色值）

设计目标：冷色环境 + 冷色主角 + 单一暖色焦点，金色仅保留给纪录。

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面背景（棋盘外） | `#0F1420` | 近黑深蓝，竖屏上下留白区使用 |
| 棋盘格 A | `#17202E` | 棋盘格交替色之一 |
| 棋盘格 B | `#1C2738` | 两格明度差要小，只提示网格不抢戏 |
| 墙·主体 | `#3A4A63` | 冷灰蓝 |
| 墙·顶部亮边 | `#6E84A3` | 仅上墙/左墙或整体外沿一条 |
| 墙·内侧阴影 | `#0B101A` | 压在棋盘边缘，形成"框住"感 |
| 蛇身 | `#35C987` | 主色，冷绿 |
| 蛇身暗描边 | `#14533D` | 所有蛇节统一描边 |
| 蛇头 | `#7BE3AE` | 比蛇身亮一档，配形状与眼睛区分 |
| 蛇头·舌尖（可选 1–2px） | `#EAF0F8` | 仅蛇头前端一小点，强化朝向 |
| 食物 | `#FF6B4E` | 暖橙红，全场唯一暖色 |
| 食物·高光 | `#FFD7C2` | 菱形内小圆点，制造"亮核" |
| 食物·外发光 | `#FF6B4E` 透明度 25–35% | 柔和光晕，不扩散到邻格之外 |
| 危险/死亡 | `#FF4D5E` | 仅死亡瞬间与危险反馈使用 |
| 破纪录金 | `#FFD166` | 仅纪录标识与破纪录特效 |
| UI 主文字 | `#EAF0F8` | 近白 |
| UI 次文字 | `#93A3BC` | 标签、提示语 |
| UI 交互强调 | `#4CC9F0` | 主按钮描边/焦点态 |

色彩纪律：

- 常规游玩时屏幕上暖色只允许出现一个像素源：食物。UI、蛇、棋盘均不引入暖色。
- `#FF4D5E` 是"出事"专用色，不得用于装饰；`#FFD166` 是"荣耀"专用色，按钮与普通 HUD 不使用。
- 绿色蛇与红色食物是传统搭配，但二者**必须同时有形状差（圆角方块 vs 尖角菱形）与明暗差**，色盲场景下仍可分辨；另需在红绿色盲模拟下复核（验收项）。

## 4. 明度（对比）层级

按灰度明度从高到低固定排序，任何素材不得越级：

1. 食物亮核 / 破纪录金（最高）
2. 蛇头
3. UI 主文字
4. 蛇身
5. 墙亮边 → 墙主体
6. 棋盘格 B / A
7. 页面背景（最低）

关键对比要求：

- 蛇头对棋盘格：明度差 ≥ 50%；蛇身对棋盘格 ≥ 35%。
- 食物即使去掉发光，主体 `#FF6B4E` 对棋盘格仍要有显著明度差（亮于蛇身一档）。
- HUD 文字不直接压在棋盘格纹上，需置于纯色留白区或带半透明深色底板（底板规格归 UI_UX_SPEC）。

## 5. 材质感与细节密度

- 总体材质：**哑光平涂 + 一层克制的辉光**。无渐变拟物、无纹理贴图、无噪点；允许的渐变只有两类：食物外发光（径向、低透明度）、墙面内外的明暗边（线性、1–2px）。
- 细节密度分级：
  - 棋盘：零装饰，仅两色交替。
  - 墙：两层细节（亮边、内投影），不做砖缝。
  - 蛇身：每节零或一个细节（暗描边即可），全长再长也不增加单节纹样，避免高速时闪烁。
  - 蛇头：细节密度最高——眼睛、略宽前端、可选舌尖，但全部元素合计不超过 5 个形状。
  - 食物：3 个形状（菱形、亮核、光晕）。
- 19px/格尺度下的收敛规则：任何小于设计坐标 3px 的细节默认删除（描边除外），蛇头眼睛在设计坐标中不小于 5×5px，确保缩小后仍是可辨的两个点。

## 6. 字体特征（中文）

- 文字性格：**现代、方正、街机标牌感**；笔画等粗或弱对比，字面饱满，重心居中偏几何；不要书法体、手写体、细衬线。
- 无授权字体确定前的执行方向：
  - 首选方向：开源中文字体中的几何黑体（如思源黑体 Heavy/Bold 字重，或类似宽扁街机字形的免费可商用字体），标题用 Bold 以上字重并加宽字距。
  - 数字与分数：允许使用等宽/几何感的数字字形（与中文同族字重或配套拉丁字符），分数跳动时字宽不变化。
  - 回退栈：系统中文无衬线（PingFang SC / Microsoft YaHei / sans-serif），并在字体未加载时保证布局不破。
- 字重层级最多三级：标题（Heavy）、正文与按钮（Medium/Bold）、标签（Regular）。不通过换字体区分层级。
- 标题"贪吃蛇"三个字可做方形外框/发光处理（呼应 UI 标牌语言），但不做立体描金、不做文字渐变。

## 7. 动效性格

性格关键词：**干脆、弹性很小、收尾干净**。像机械步进，不像软体动画。

- 常态移动：蛇以步进为节奏，相邻格间做短促补间（缓动用 ease-out，时长占当前步进间隔的 50–70%，速度加快时自动缩短；6 步/秒时约 100ms，14 步/秒时约 40–50ms），蛇头允许 ≤10% 的前倾挤压，禁止拖影和长滑行动画。
- 食物待机：极轻微缩放呼吸（±4%，约 1.2s 循环）与缓慢自旋（菱形轮廓几乎不动，主要靠高光位置变化），节奏与蛇速无关，不制造紧迫感。
- 吃食物（≤300ms）：食物在原位"砰"地爆开——菱形快速放大至 160% 并消失，一圈亮色环扩散约一格半径，新食物在新位置以 60%→100% 弹出出现。
- 死亡（评审定值 500ms；填满结局 800ms）：蛇头处闪 `#FF4D5E`、蛇身逐节短促熄灭或整体下沉变暗，配合轻微屏震；全程红色，但"死因位置"用星形/叉形轮廓加强，不只闪色。
- 破纪录：结算时金色粒子/光点从分数处向上散开（一次性、约 700ms），纪录标识用印章/星标等**形状**承载，金色只是第二层。
- 转场：
  - 开始 → 游戏中：快速淡入 + 棋盘轻微"落位"（scale 0.98→1，约 200ms），表达"开机"。
  - 暂停：棋盘整体降亮（压一层 30–40% 深色）并冻结一切动画，像拉开幕布后的静止舞台；不做花哨模糊。
  - 死亡 → 结算：短暂暗下后结算卡片上浮淡入（约 250ms），情绪是"收手、看成绩"，不是嘲讽。
- 尊重减弱动效偏好：系统开启"减少动态效果"时，屏震、粒子与缩放降级为淡入淡出（实现约束，美术需提供无动效也成立的静态帧）。

## 8. 各元素如何共享语言又保持层级

### 8.1 背景与棋盘格

- 棋盘是唯一的"游戏空间"：两色低对比方格（`#17202E` / `#1C2738`）平铺，无间隙（与 cellSize 32、无间隙决策一致）。
- 格纹只承担位置读数功能，不得出现高亮格、扫描线、流动光效；速度加快时格纹不变化（速度信息由蛇本身传达）。
- 棋盘外页面背景 `#0F1420` 纯色，保证棋盘像悬浮其上的发光面板。

### 8.2 蛇：蛇头、蛇身与朝向

蛇头与蛇身的区分使用**三重冗余**，任何一重单独失效仍可辨认：

1. **明度**：蛇头 `#7BE3AE` 亮于蛇身 `#35C987`；
2. **形状**：蛇头前端略宽、带两只眼睛；蛇身等宽无眼睛；
3. **位置语义**：蛇头永远是链条最前端。

- 朝向表达：两只眼睛靠前排布 + 前端可选浅色舌尖；转向时蛇头先到位，身体跟随。眼睛在四个朝向下做四组朝向姿态（瞳点贴前进方向一侧）。
- 蛇身段之间用统一暗描边分隔；若采用连体带状渲染，弯曲处必须保持格位圆角逻辑，不出现脱离网格的触手感。
- 状态变化：
  - 正常：平涂哑光；
  - 刚吃到食物的一步：蛇头/新节一个极短亮闪（提亮 ≤100ms）；
  - 死亡：见第 7 节，整蛇变暗而不是仅变色。
- 初始 3 节时层级即完整：头、身一眼可分，不依赖长度。

### 8.3 食物

- 菱形 + 亮核 + 柔光，与蛇的圆角方块在形状语言上直接对立；它是画面最亮、最暖的唯一元素。
- 出现/被吃均有位置明确的动效，帮助玩家在高速下锁定刷新点。
- 不使用苹果、圆点等与蛇身轮廓近似的造型。

### 8.4 墙 / 边界

- 四面一体的硬框：直角、亮边在内、投影压棋盘，表达"不可逾越的机器边缘"。
- 墙本身平时完全静止、不发光不脉冲；危险感来自硬度与内投影，而不是警报色。
- 仅当死亡原因是撞墙时，碰撞点那一段墙才短暂参与死亡闪光。

### 8.5 UI（开始 / 暂停 / 游戏结束 / HUD）

- UI 与世界同族：蛇/按钮的圆角家族、页面的深色、发光描边；UI 像盖在棋盘上方的半透明标牌，不做拟物皮革/金属。
- 开始界面：标题"贪吃蛇"居中（方形标牌处理），下方一个主按钮；可在标题与按钮之间放静态蛇形母题（见 9.2），其余全部留白。
- HUD：分数是一级信息，最高分二级，暂停入口为图标按钮；分数变化时数字做一次短跳（scale 1→1.15→1，约 150ms），不滚动不翻牌。
- 暂停：遮罩 + "已暂停" + 继续/退出；文案与按钮次序列表归 UI_UX_SPEC，本文只规定其视觉为"冻结舞台上的卡片"。
- 游戏结束：结算卡片展示本局得分与历史最高分；破纪录时金色星标/印章与数字并列出现；棋盘填满的稀有结局使用区别于死亡的视觉——**不出现红色与叉形，改为金色、安静的满盘辉光**，文案措辞待 GDD 未决项。
- 图标（暂停、继续、重开、退出）使用与墙一致的线性硬边风格，线宽统一。

### 8.6 特效总表

| 事件 | 颜色 | 形状载体 | 时长（约） |
|---|---|---|---|
| 吃食物 | 食物暖色 + 白 | 扩散环、点状爆开 | ≤300ms |
| 死亡 | `#FF4D5E` | 叉形/星形闪、屏震、逐节熄灭 | 500ms（填满 800ms） |
| 破纪录 | `#FFD166` | 星标/印章、向上光点 | ≤700ms |
| 填满棋盘 | 金色 | 满盘柔和辉光，无震动 | 由结算演出定 |

所有特效只出现在独立特效层（见第 10 节），不改写底层素材颜色，便于减弱动效与性能降级。

## 9. 玩家面向屏幕的视觉识别

### 9.1 焦点主体与母题

- **局内焦点母题：蛇头与食物之间的"视线张力"。** 画面所有静息元素都为此让路——格纹低对比、墙体静止、HUD 靠边。
- **全局品牌母题：一条盘成方形的蛇。** 用于开始界面主视觉、加载占位、文档与图标方向；它与棋盘同形（方形、网格感），让标题画面与游戏画面是同一个世界。

### 9.2 标题画面主体

- 主体构图：上方标题标牌，中部静态盘蛇母题（可做极轻微呼吸，不游走），下方主按钮；不放棋盘实拍、不放食物乱飞，标题画面是"安静的开机位"。

### 9.3 留白与安静区

- 竖屏：棋盘上下方纯色区域是法定安静区，HUD 与触控提示生活在这里，禁止加装饰粒子。
- 横屏：棋盘两侧留白承担同样角色；HUD 优先贴棋盘边缘而不是飘在页面四角。
- 任何界面必须保留一个无元素、无辉光的呼吸区（开始界面即四周大面积 `#0F1420`）。

### 9.4 转场情绪

- 开局 = 通电落位（轻快、确定）；暂停 = 舞台静止（克制、无焦虑）；死亡 = 一记短促的红灯（干脆、不羞辱）；结算 = 收手上浮（面对成绩）；破纪录 = 一次性金色绽放。转场不使用旋转、翻页等与街机基调无关的演出。

## 10. 分层、透明与宽高比适配

渲染分四层，从下到上相互独立，便于单独替换与降级：

1. **背景层**：纯色 `#0F1420`，全屏平铺，无透明。
2. **棋盘/玩法层**：墙（整体一张框体或四条可拼接边，接口处必须无缝）+ 640×640 棋盘（格纹需支持平铺，禁止依赖整张 640 位图）+ 蛇与食物的游戏元素。
3. **特效层**：透明叠加（吃食物环、死亡闪、金色粒子），允许加法混合；关闭特效时玩法层独立完整。
4. **UI 层**：HUD、遮罩、卡片、按钮，独立于棋盘缩放；遮罩使用半透明深色而非对玩法层做后处理模糊（降级友好）。

适配要求：

- 棋盘始终保持正方形、按窗口等比缩放、居中；设计坐标 640×640 为唯一基准，不为不同屏幕改画元素。
- 桌面横屏：棋盘居中，两侧露出背景层；HUD 位于棋盘上方/侧面安静区。
- 手机竖屏：棋盘以屏宽为基准（此时每格约 19px），HUD 在上、触控方向控件在下（是否启用方向控件归交互契约文档）；所有关键辨识元素必须在 19px 下通过检查：蛇头双眼镜仍为两点、食物仍为尖角菱形、墙框仍可见亮边。
- 需要平铺的元素：棋盘格纹、墙体边条；需要独立透明图层的元素：蛇各姿态、食物、全部图标与特效。任何素材交付不得把 UI 烘进棋盘整图。

## 11. 素材一致性标准（生成 / 检索 / 程序化通用）

无论素材来自 AI 生成、素材库检索还是代码程序化绘制，入库前必须同时满足：

1. **形状家族**：活物/界面为规定圆角，墙为直角，食物为尖角菱形；无外来风格（无像素颗粒、无手绘描边、无 3D 渲染感混入）。
2. **色板纪律**：像素颜色取自第 3 节色板（抗锯齿过渡色除外）；不引入色板外色相。
3. **描边与明度**：蛇系元素统一 2px（设计坐标）`#14533D` 暗描边；明度排序符合第 4 节。
4. **尺度验证**：素材在 32px 与 19px 两档下各检查一次，细节丢失时先删细节再考虑放大。
5. **坐标与枢轴**：以格位中心或左上角为统一枢轴（ASSET_PLAN 定），蛇节、食物必须能逐格对齐，不允许归一化后破坏装配关系。
6. **去色与色盲检查**：灰度截图仍可识别五类元素；红绿色盲模拟下蛇/食物可分。
7. **来源与成本**：检索素材需确认可商用授权、风格兼容，并评估其运行时体积是否值得；生成素材需可复现（保留提示词与种子）。程序化绘制需参数全部来自配置，色值与圆角不得硬编码散落多处。
8. **静帧成立**：暂停帧、无特效帧、无动效帧各自构图完整，不依赖播放瞬间才好看。
