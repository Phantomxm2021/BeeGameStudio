# 贪吃蛇 UI/UX 设计规格（UI_UX_SPEC）

- 版本：v0.1（作者批次草稿，待统一评审）
- 作者：Bee Game Studio
- 日期：2026-09-30
- 适用平台：Web（React，2D，风格化）
- 上游依据：`GDD.md`（状态/规则）、`LEVEL_SCENE_DESIGN.md`（可见性）、`BALANCE_DESIGN.md`（数值）、`ART_DIRECTION.md`（视觉语言）、`TECHNICAL_DESIGN.md`（模块/绑定）
- 本文拥有屏幕空间分配与布局选择的唯一权威；其他文档只引用。

---

## 1. 坐标与约定

- 所有 UI 使用屏幕空间逻辑像素，原点左上，+X 右、+Y 下；anchor/pivot 为归一化 [x,y]，`position` 为相对 anchor 的父级局部偏移，子 pivot 默认与 anchor 相同。
- 参考分辨率（referenceResolution）：桌面基础构图 **1280×720**；它是设计参考，不是固定宿主尺寸，屏幕根恒按实际 viewport 解析。
- 最小支持宿主：**390×844**（手机竖屏）。目标 viewport 列表（targetViewports）：`[1280,720]`、`[1024,640]`、`[390,844]`。
- 世界取景（相机 letterbox）与屏幕 UI 适配各自独立（TECHNICAL_DESIGN 第 7 节）。

### 1.1 布局选择条件（优先级从高到低）

| 优先级 | 条件 | 选用构图 |
|---|---|---|
| 1 | height > width（在 compact 之后判定） | **竖屏构图（portrait）**：HUD 顶条 60 + 游戏视图（宽）+ 底部方向键区 |
| 2 | viewport 宽 ≤ 600 | **紧凑构图（compact）**：同桌面骨架，间距/字号按紧凑值 |
| 3 | 其余 | **桌面构图（desktop）**：HUD 顶条 64，游戏视图居中 |

- 条件同时满足时先应用 compact 再叠加 portrait（portrait 优先）。compactMaxWidth = 600。
- 输入能力与 viewport 形状是两件事：竖屏构图只由形状触发；桌面浏览器的窄窗口同样可能进入 compact。触控不自动触发 portrait。

## 2. 共享页面骨架（区域分配，只定义一次）

游戏相关各屏（HUD、暂停、结算）共享同一骨架；开始界面独占全屏，不走骨架。

```
桌面 1280×720                          竖屏 390×844
┌────────────────────────────┐        ┌──────────────┐
│ HUD 顶条 64（拉伸）         │        │ HUD 顶条 60   │
├────────────────────────────┤        ├──────────────┤
│                            │        │              │
│      游戏视图 R            │        │  游戏视图 R  │ ← 棋盘 390×390
│  (HUD 之下全部剩余)        │        │              │
│                            │        ├──────────────┤
│   棋盘正方形居中 letterbox │        │ 方向键区 394 │
│                            │        │（见 4.4）    │
└────────────────────────────┘        └──────────────┘
```

| 区域 | 桌面行为 | 竖屏行为 |
|---|---|---|
| HUD 顶条 | anchorMin/Max 横向拉伸，固定高 64 | 固定高 60 |
| 游戏视图 R（内容宿主元素 id：`game-view`） | 占 HUD 以下全部空间；桌面参考 1280×656 | 固定取屏宽为正方形棋盘，参考 390×390，y=60 |
| 方向键区 | 不存在（桌面隐藏节点） | 高 394，y=450；属预留区而非覆盖层，永不与棋盘重叠 |
| 覆盖层（暂停/结算） | 全屏半透明遮罩 + 居中卡片 | 同构，卡片改用竖屏尺寸 |

- **预留区**：HUD、方向键区——始终不显示棋盘内容；**允许覆盖区**：仅暂停与结算遮罩，且只在对应状态出现。游戏进行中棋盘 400 格上方无任何 UI（满足 LEVEL_SCENE_DESIGN 3.4）。
- 安全区：竖屏时 root padding 纳入设备安全区（顶部刘海 ≥ 状态栏、底部 Home 指示条 ≥ 16）；方向键区底部 padding 24 已覆盖。
- 尺寸变化行为：HUD 拉伸、游戏视图随宿主缩放并由相机 letterbox 呈现棋盘；方向键区固定不缩放（控件固定尺寸是有意决定）；不出现滚动条。

## 3. 界面清单与状态总表

状态机闭集（GDD 第 6 节）：`loading → start → playing ↔ paused → settling → gameover`（+error）。每个 UI 文档的可见性矩阵：

| 文档（建议 id / kind / loadPhase） | loading | start | playing | paused | settling | gameover |
|---|---|---|---|---|---|---|
| `ui-start` / ui-screen / startup | – | 可见 | 隐藏 | 隐藏 | 隐藏 | 隐藏 |
| `ui-hud` / ui-hud / startup | – | 弱化* | 可见 | 隐藏 | 隐藏 | 隐藏 |
| `ui-pause` / ui-screen / startup | – | – | – | 可见 | – | – |
| `ui-gameover` / ui-screen / startup | – | – | – | – | 演出后可见 | 可见 |
| `ui-dpad` / ui-hud / startup（仅 portrait 启用） | – | 隐藏 | 可见 | 隐藏 | 隐藏 | 隐藏 |
| `ui-system`（加载/错误外壳，非玩家流程屏） | 可见 | 隐藏 | – | – | – | 错误时可见 |

静音按钮（action `toggle-mute`，绑定 `muted`）在 start 与 playing 两种状态可见：start 屏实例位于右上角（id `mute-btn`），playing 时实例位于 HUD（id 同为 `mute-btn`）；暂停与结算遮罩出现时随 HUD 一并隐藏。静音状态持久化规则引用 `AUDIO_DESIGN` 第 5 节，本文不重复。

\* start 态 HUD 可保留但降透明度或整体隐藏，由作者态数据 enabled 决定；实现不得在代码里另造显隐规则。

## 4. 各屏幕详细规格

### 4.1 开始界面 `ui-start`

- 进入：应用引导完成（GDD/TECHNICAL：loading→start）；或从暂停、结算选择返回。退出：开始游戏 → playing。
- 构图（转化自 ART_DIRECTION 9.2：安静的开机位）：column 居中、大留白；视线顺序 **标题 → 盘蛇母题 → 主按钮**。
- 元素：

| id | role | 内容来源 | 动作/结果 |
|---|---|---|---|
| `title` | text | 静态文案"贪吃蛇" | – |
| `motif` | shape（视觉用途：盘成方形的蛇形母题，矢量/代码绘制，见第 7 节） | 静态 | – |
| `start-btn` | button | "开始游戏" | `start` → 初始化一局 → playing |
| `mute-btn` | button | 图标随 `muted` 切换（有声/静音两态，形状差异不仅靠颜色） | `toggle-mute` |

- 层级：标题为主视觉（Heavy），母题为品牌呼应（不抢主按钮焦点），主按钮是本屏唯一可操作元素。
- 桌面尺寸：标题 480×96 @ (400,156)；母题 160×160 @ (560,292)；按钮 280×72 @ (500,492)；静音键 88×44 @ (1180,12)。
- 竖屏尺寸：标题 342×80 @ (24,248)；母题 140×140 @ (125,360)；按钮 240×64 @ (75,532)；静音键 56×40 @ (322,12)。
- 状态：按钮默认/悬停（描边加亮）/按下（scale 0.97）/键盘焦点（`#4CC9F0` 焦点框）；无禁用态。
- 键盘：空格/回车直接开局；焦点默认落在 `start-btn`。

### 4.2 HUD `ui-hud`

- 进入：playing；退出：暂停或结束。row + space-between，信息层级：**当前分数（一级）＞ 暂停入口 ＞ 最高分（二级）**。
- 元素：

| id | role | 绑定 | 说明 |
|---|---|---|---|
| `score` | text | `score`：显示"分数 {score}" | 字号桌面 28 / 竖屏 22；预留最大四位 |
| `hiscore` | text | `highScore`："最高分 {highScore}"（竖屏简写"最高 {}"） | 次级色 |
| `pause-btn` | button | action `pause` | 图标按钮（线性图标），playing 时可点 |
| `mute-btn` | button | action `toggle-mute`，`muted` 状态切换图标 | 与暂停键同尺寸图标位 |

- 桌面矩形：score [24,12 264,52]；hiscore [596,12 836,52]；pause-btn [1168,12 1256,52]。
- 竖屏矩形：score [12,10 128,50]；hiscore [148.7,10 240.7,50]；mute-btn [261.3,10 309.3,50]；pause-btn [330,10 378,50]。桌面 HUD 静音键位于暂停键左侧（88×40）。
- 文本处理：数字为等宽字形，跳动时不引起字宽变化；最大 3970 已纳入草稿宽度（见第 6 节）。
- 反馈：分数变化时数字短跳 scale 1→1.15→1（约 150ms），不滚动不翻牌；每步移动无反馈动画。

### 4.3 暂停覆盖层 `ui-pause`

- 进入：playing 中触发 `pause`；退出：`resume` → playing，`quit` → start。
- 全屏遮罩 `#0F1420` 60% 透明（不模糊，降级友好）；居中卡片。
- 元素（column，stretch）：`panel-title`"已暂停"、`resume-btn`"继续游戏"（action `resume`，主操作）、`quit-btn`"退出到主菜单"（action `quit`）。
- 桌面卡片：380×300 @ (450,210)；竖屏：380×300 @ (5,272)。
- 规则约束（GDD 5.2/5.4）：进入暂停时清空转向队列；卡片出现前的按键不触发退出；键盘 Esc/P/空格映射为 resume，焦点默认在 resume-btn。

### 4.4 结算覆盖层 `ui-gameover` 与方向键区 `ui-dpad`

**结算：**
- 进入：settling 演出结束（GDD 5.4：过渡期间忽略输入）；退出：`restart` → 新一局 playing；返回主菜单 → start。
- 元素（column）：

| id | role | 绑定/内容 | 说明 |
|---|---|---|---|
| `end-title` | text | endReason=board-full 时文案改为"棋盘填满！"，否则"游戏结束" | |
| `record-badge` | shape | `newRecord`=true 时 enabled 并显示"新纪录"（金色星标形状，形状承载而非仅金色） | 默认隐藏 |
| `score-line` | text | "本局得分 {score}" | |
| `hiscore-line` | text | "历史最高 {highScore}" | |
| `restart-btn` | button | `restart`（主操作，焦点默认位） | |
| `home-btn` | button | `quit`（返回主菜单） | |

- 桌面卡片：400×420 @ (440,150)；竖屏卡片：340×440 @ (25,202)。
- board-full 视觉：无红色/叉形，金色安静基调（ART_DIRECTION 8.5），仅文案与色调差异，布局相同。
- 键盘：空格/回车 → restart。

**方向键区（仅 portrait 构图启用）：**
- 390×394，3×3 grid（gap 8、padding [16,16,24,16]），十字 4 个按钮：

| id | 动作 | 矩形 |
|---|---|---|
| `pad-up` | `turn-up` | [138,16 252,120] |
| `pad-left` | `turn-left` | [16,128 130,232] |
| `pad-right` | `turn-right` | [260,128 374,232] |
| `pad-down` | `turn-down` | [138,240 252,344] |

- 按钮按下即时触发意图，支持按住连点不需要（每步至多消费一个转向，GDD 5.2）；按压态有视觉高亮。
- 全屏滑动手势在任何 portrait 状态都同时可用（棋盘区域触发），与方向键汇入同一意图流；滑动阈值与误触处理在交互契约/实现中按本规格热区执行：滑动识别区 = `game-view` 宿主元素，方向键区不响应滑动。

### 4.5 系统外壳：加载与错误

- loading：居中静态母题 + "加载中"文本；error：中文错误信息 + "重试"按钮（重新走引导，TECHNICAL_DESIGN 9.2）。非关键资产失败不进 error，静默降级。

## 5. 交互、焦点与导航

- **键盘**：转向（方向键/WASD）；start→`start`、空格/P→pause/resume、gameover→`restart`；Esc→暂停/继续。焦点环统一 `#4CC9F0`，焦点只在当前可见屏的控件间移动；playing 时焦点不影响转向。
- **鼠标**：仅点击控件；点击非控件区域不产生任何结果。
- **触控**：`game-view` 内滑动 + 方向键按钮；系统按钮在全部触控屏上尺寸 ≥ 48×40（HUD 暂停键竖屏 56×40，图标居中满足触达）；多点触控取第一有效手势。
- 意图 phase 门控统一在 GameStore 入口实施：非 playing 转向丢弃、settling 期间 restart 不生效（TECHNICAL_DESIGN 5.1/6）。
- 首次用户手势同时解锁音频（AUDIO_DESIGN 引用本规则）。

## 7. 对 ASSET_PLAN 的视觉用途需求

| 视觉用途 | 形式建议 | 槽位 |
|---|---|---|
| 开始界面盘蛇母题 | 矢量/代码绘制优先（与棋盘同形的方形盘蛇） | `motif` |
| 暂停/重开/退出/方向箭头/静音图标 | 线性硬边图标，统一线宽；静音需有声/静音两个可换图标 | 各 button |
| 卡片底板 | 可 nine-slice 圆角面板（1px 发光边） | 各 panel |
| 新纪录星标 | 形状优先的金色星/印章 | `record-badge` |
| 字体 | 几何中文黑体（Heavy/Medium/Regular 三级）+ 等宽数字 | 全部文本 |

- 颜色与圆角规则引用 ART_DIRECTION，不在此重复；装饰性素材不是本游戏所必需，不请求插画。
- 素材清单、文件规格与资源 id 由 ASSET_PLAN 汇总；节点 id 与本文表格一致，运行时按 id 绑定。

## 8. 动效反馈规格（目的/触发/时机）

| 反馈 | 目的 | 触发 | 表现与时长 |
|---|---|---|---|
| 分数短跳 | 确认进食已计分 | score 变化 | scale 1→1.15→1，约 150ms |
| 开局落位 | 表达"通电" | start 确认 | 淡入+scale 0.98→1，约 200ms |
| 暂停压暗 | 状态静止 | pause | 30–40% 深色压层，无模糊 |
| 结算上浮 | 收手看成绩 | settling 结束 | 卡片上浮淡入约 250ms |
| 按钮按压 | 操作确认 | pointerdown | scale 0.97，松开即回 |

- 减弱动态效果（prefers-reduced-motion）：以上一律降级为淡入淡出；美术/技术须提供无动效成立的静态帧。事件语义与 AUDIO_DESIGN 对齐（同一事件视听同时发生）。

## 9. 未决设计决策

1. settling 演出最终时长（当前技术默认 0；美术建议 500–800ms 死亡演出）——规则已定（期间输入门控），数值待统一评审。
2. start 态 HUD 是隐藏还是弱化显示，待首屏视觉实现时定。
3. 滑动手势最小位移阈值与对角线判定的具体像素值（热区已定：`game-view`），留给交互契约/实现，不改变本规格布局。
4. "棋盘填满"最终中文文案（占位"棋盘填满！"）。静音入口位置已决（开始屏与 HUD 右上角图标）。
