## 1. 目标与一句话概念

把 GDD §1 的玩家承诺——"移动挡板、控制反弹角度，在有限生命内清空砖阵"——变成一眼能读懂的画面：

> **"深夜街机店里发光的一块塑料球场：糖果色砖阵压在深蓝夜空上，一颗暖白球是唯一主角，一切闪光都为它的碰撞让路。"**

关键词不是形容词，而是三条可执行规则：

1. **厚描边 + 圆角块体**：所有场上物体像被深色墨水线勾过边的街机塑料件，轮廓优先于质感。
2. **明度分层**：深蓝暗背景（L≈10–18%）托住中明度砖阵（L≈50–65%），再托住高明度的球与挡板（L≈75–95%）。
3. **单主角**：场上永远只有一颗球（GDD §3.2），画面的对比预算、特效预算、安静区域全部围绕"球轨迹可读"分配。

玩家可见范围严格限定为 GDD §1.1：单屏、一个固定砖阵关卡、普通砖/加固砖、单挡板、单球、分数/生命 HUD、开始/暂停/胜利/失败界面。视觉不得暗示任何超出此范围的内容（见 §13）。

## 2. 形状语言（Shape Language）

形状是本项目第一识别系统，颜色是第二。所有物体必须在"去色、缩小、运动中"三种条件下仍可归类。

### 2.1 全局几何规则

- 基础形：**圆角矩形族**。砖、面板、按钮、HUD 信息盒同源，靠尺寸、描边粗细和内部结构区分身份。
- 圆角以"短边比例"而非固定像素定义，保证缩放一致：
  - 砖块圆角半径 ≈ 砖高的 14–18%；
  - UI 面板圆角 ≈ 面板高的 4–6%；
  - 小信息盒（HUD 分数盒等）圆角 ≈ 自身高的 10–15%。
- **挡板是全圆角胶囊形（半径 = 高度 1/2）**，与砖块家族形成刻意的轮廓反差——它是场上唯一非矩形主体。
- **球是正圆**，永远正圆；形变只允许发生在碰撞瞬间（§7），静止帧必须是圆。
- 所有描边使用同一支"墨水"：深色近黑靛 `#0F0F22`，外侧或居中描边、圆角连接（round join），不允许硬折线接头。
- 描边粗细以"参考高度 1080 的设计像素"为基准，运行时等比缩放：

| 用途 | 基准粗细 | 说明 |
|---|---|---|
| 普通砖 | 3px | 砖块家族基准线 |
| 加固砖 | 5px | 用更重的轮廓编码"更硬"（§10） |
| 挡板 / 球 | 5px | 主角享受最重视觉权重 |
| UI 常规 | 3px | 信息盒、次级按钮 |
| UI 强调 | 5px | 主按钮、结算关键数字外框 |
| 裂纹 / 碎屑边 | 2–3px | 与砖本体同一墨水 |

- 最小描边不得低于 1.5 物理像素；若某缩放下低于下限，优先删细节（铆钉、暗纹）而不是减细主线（§10.4）。

### 2.2 形状气质

- 友善、结实、街机感：圆角大、线条粗、转角钝。不出现锐角尖角（裂纹除外，裂纹是"伤害"的专属语言）。
- 禁止：写实比例、有机自由曲线、纤细等距线稿、赛博霓虹的锐角切字形。允许少量"切角"细节作为加固砖的结构件（见 §10），但整体外轮廓仍保持圆角。

## 3. 调色板（Palette）

颜色按职责分配，不按个人审美。HEX 为参考锚点，色相/饱和度/明度区间是约束。

### 3.1 色板总表

| 角色 | 色相区间（HSB/HSL） | 参考 HEX | 用途 |
|---|---|---|---|
| 背景底色 | H 235–255，S 25–40%，L 10–18% | 顶 `#1E1E42` → 底 `#13132B` | 全屏纵向渐变，最暗层 |
| 场地结构 | 同背景色系，L 18–28% | `#2A2D5C` | 三边边界的微弱结构光；不做实墙 |
| 底线（危险提示） | H 345–355，L 55–65% | `#FF5C7A`（α 18–25%） | 漏球边界的虚线暗示；仅在漏球瞬间短暂提高到实色（§11） |
| 普通砖·珊瑚 | H 0–12 | `#FF6B6B` | 砖阵行序装饰色之一 |
| 普通砖·橙 | H 25–35 | `#FF914D` | 同上 |
| 普通砖·琥珀黄 | H 40–48 | `#FFD166` | 同上 |
| 普通砖·绿 | H 125–140 | `#6FCF8F` | 同上 |
| 普通砖·蓝 | H 205–220 | `#5AA9FF` | 同上 |
| 普通砖·紫 | H 255–270 | `#9B7EDE` | 同上 |
| 加固砖·钢灰蓝 | H 225–240，S 15–28%，L 52–64% | 面 `#8A90B5`，亮 `#A7ADCF`，暗 `#6E7499` | 低饱和冷灰，区别于普通砖的糖果色 |
| 挡板（主角冷色） | H 185–195，S 80–95%，L 60–72% | 顶 `#A6F4FF` → 底 `#2FB9D9`（主调 `#5EE7FF`） | 场上唯一高饱和青色 |
| 球（主角暖色） | H 45–52，S 60–90%，L 82–95% | 芯 `#FFF6BF`，晕 `rgba(255,231,120,.35)` | 场上明度最高点 |

| 墨水 | — | `#0F0F22` | 全部描边、裂纹、投影偏移 |

### 3.2 用色规则

- **普通砖的多色只编码"行序装饰"，不编码玩法信息。** 任何色相的普通砖规则完全相同（GDD §3.3）；因此禁止把砖色与分值、危险度挂钩做暗示。
- **加固砖统一低饱和钢灰蓝**，全砖阵不随行变色。它与普通砖的区分首先靠描边/结构/纹理（§10），颜色只是辅助。
- 全画面饱和色总量受控：高饱和只出现在砖、挡板、球与 UI 强调处；背景与场地必须灰、暗、安静。
- 强调金 `#FFD166` 不用于普通砖琥珀黄的同一语境（砖在场上，金用于 UI 与结算），避免"新纪录金"与砖块混淆。
- 颜色不作为唯一信息载体：任何需要玩家识别的状态（砖类型、受损、生命、胜负、新纪录）必须同时有形状/描边/纹理/文字/运动中的至少一项冗余编码（§10）。
- 通过红绿色盲模拟与灰度截图验收（§14）。

### 3.3 明度对比策略

三级明度阶梯是可读性的骨架，任何特效不得破坏：

1. 背景 L 10–18%（最暗）；
2. 砖块 L 50–65%（中）；
3. 挡板 L 60–72% 但靠唯一青色色相 + 粗描边；**球 L 82–95%（最亮，全画面对比最高点）**。

- 任何 FX 粒子的明度不得在球的运动走廊内超过球；碰撞闪光允许短暂高亮度，但范围限制在碰撞点局部（§9.4）。
- HUD 文字对比遵循 UI 主文字对背景 ≥ 4.5:1；当前分数是 HUD 内对比最高项，生命图标次之。

## 4. 材质感、渐变与细节密度

2D Web 项目，材质全部用平面手法"暗示"，不做写实渲染。

- **砖**：哑光塑料感。平涂 + 纵向两档渐变（顶比底亮约 8–10% L）+ 顶部内高光（1px、白 α25–30%、沿圆角走）。无投影投射到其他砖。
- **加固砖**：硬质结构件。外体同砖材质，内部多一层内嵌面板（inset panel）：面板顶边 1px 暗线、底边 1px 亮线，形成"冲压钢板"错觉；四角可有小圆点铆钉（亮 `#DDE2FF`）。
- **挡板**：上釉塑料/糖果壳。胶囊形渐变跨度比砖略大（顶底 L 差 15–20%），顶部一段短高光（宽度约为体长 1/3，白 α35%），暗示可操控的"器具"。
- **球**：自发光小球芯。径向渐变（中心近白 → `#FFF6BF`），一个偏心小白点高光；外层允许低强度柔光晕（α≤35%、半径≤球径 1.8 倍），光晕是装饰不是碰撞依据，任何时刻球本体墨线完整。
- **背景**：纯渐变 + 极弱微纹理。允许点阵/细网格的可平铺纹理，alpha 3–6%，tile 单元 24–48px（基准值）；或极淡竖向暗光束（alpha ≤ 8%）。禁止星空、光轨、闪烁灯条等抢夺注意力的背景动画。
- **细节密度上限**：每个场上物体只允许一个"细节要点"——砖是高光线，加固砖是内嵌板（铆钉属板内细节，二者整体算一个要点），挡板是高光段，球是高光点。超出即删减。背景细节密度不高于纹理层本身。
- 不使用照片纹理、法线、写实金属反射、投影模糊长阴影。界面层如需玻璃感，用半透明平涂 `#1B1D3D`（α 80–90%）实现；背景模糊为可选增强而非基线。

## 5. 字体方向（Typography）

游戏内文字全部中文（GDD 头部），数字为拉丁/阿拉伯数字。字体气质服务于"厚街机、友好、有力"，不承担装饰纹样职能。

### 5.1 中文标题字体

- 气质：**厚重、饱满、偏几何的粗黑或圆角黑体**——字面方正、笔画等粗感强、中宫开阔，小字号下也敦实。参考方向：思源黑体 Heavy / 站酷类黄油体 / 圆角粗黑这一谱系。
- 允许的标题处理：墨水色 2–4px 描边 + 同墨水 3–5px 右下偏移的挤出投影（实心不渐变），模拟街机招牌字。字间距正常或微紧。
- 禁止：书法体、宋体衬线、手写体、纤细科技体、故障(glitch)风、霓虹管字。

### 5.2 正文与按钮

- 与标题同族的中粗/常规字重，不引入第二套中文家族。
- 按钮文字用主文字色压在实色按钮上（深色字压金按钮时用墨水位 `#0F0F22`），保证小屏触控距离可读；具体最小字号由 UI_UX_SPEC 定义。

### 5.3 数字（分数/最高分）

硬性要求：

- **等宽数字（tabular figures）**：分数实时跳动时不得左右抖动；
- 几何感无衬线，笔画粗壮（与中文粗黑气质匹配），不允许细体或复古点阵体作为主分数；
- 数字字形在最小 HUD 尺寸下笔画不合并、洞眼（0/6/8/9）清晰；
- 分数允许比中文正文更强的"招牌感"（更紧字距或微倾斜可选），但必须仍是等宽数字。

当前分数：主文字色；历史最高分：次文字色；结算大数字：主文字色 + 墨水挤出；新纪录数值可换强调金（§11）。字体的最终选型与字号属于 UI_UX_SPEC。

## 6. 焦点主体与视觉母题

### 6.1 母题（Motif）

**"球与一道上扬的反弹弧"**——正圆 + 简洁弧线，是贯穿所有界面的唯一图形母题：

- 开始界面主视觉：放大的标题字（厚黑描边挤出）为画面焦点主体；标题旁/下方布置**一颗大比例的球，沿一道墨水弧线向上弹起，弧线末端指向一小簇砖（仅普通砖造型，或普通砖+一块加固砖，数量克制）**。该簇砖是"目标"的符号化呈现，不得画成完整砖阵的缩略图（避免暗示关卡选择）。
- 弧线在结算面板、HUD 分隔、旋转提示页中可作为角饰/分隔元素重复出现，保持同一墨水粗细规格。
- 母题只用球与弧：不得引入角色形象、机械手、街机机柜外壳插画等新设定（GDD §1.2 无剧情/角色）。

### 6.2 游戏内焦点

- 第一焦点永远是**球**，第二焦点是挡板，砖阵是静态背景信息。
- 视觉权重排序：球（最高明度 + 暖光晕）＞ 挡板（唯一青色 + 胶囊轮廓）＞ 被击中的砖（瞬时）＞ 其余砖阵 ＞ 场地结构 ＞ 背景。

### 6.3 景深与安静区域

单屏固定机位（GDD §1），不做镜头运动与视差；景深靠明度、饱和、细节密度三级差实现：

- 远景：深蓝渐变背景，弱纹理；
- 中景：场地与砖阵；
- 近景：挡板、球、FX。

**安静区域（信息真空带）**：

1. **球的运动走廊**：场地中部偏下、挡板上方的主要飞行条带——背景此处只允许纯色渐变与 α≤4% 微纹理，禁止放置装饰母题、灯束或任何移动背景元素。
2. **挡板上方一条安全带**（高度建议 ≥ 1.5 倍挡板高，最终由 UI/技术在缩放中保证）：不允许任何装饰或常驻 UI 进入，确保小屏触控时手指下方/上方的接球判断干净。
3. 装饰性大球与弧线母题只允许出现在开始/结算/暂停界面，以及游戏内砖阵上方到顶边界之间的窄条带（α 低、静态）。

满足 GDD §9："球的运动轨迹在任何时刻清晰可读，不得因特效造成碰撞判断不可辨认。"

## 7. 运动与特效气质

总性格：**脆、弹、短**。像硬塑料球砸在糖块上——反馈即时、形变夸张但回弹快、余波短。球本身匀速不加速（GDD §3.2），运动的"性格"由形变和特效而非速度变化表达。

时间令牌（参考值，供实现统一）：

- 碰撞挤压（squash & stretch）：80–120ms，快速回弹（out-back 类缓动）；
- 碎屑寿命：250–350ms；
- 碰撞闪光：≤150ms；
- 界面切换：200–300ms；
- 球的运动位移：线性，不加缓动。

### 7.1 球

- 碰撞瞬间沿接触面法向拉伸至约 110–115%、垂直方向收至 85–90%，一帧内进入、百毫秒内回正；离开发球点时沿初速度方向轻拉伸。
- 拖尾：允许仅 2–4 个残影/短拖影（α 快速衰减，长度随速度但总长 ≤ 球径 1.2 倍），拖尾不得形成实线光带遮挡碰撞面。
- Ready 待发时球在挡板上做 1 秒周期的轻微呼吸（缩放 ±5–6%、光晕微脉动），传达"可以发球"。

### 7.2 挡板

- 接球瞬间沿水平方向微挤（±6–8%）并在被击点闪一段高光；移动不带拖影、不倾斜，保持"器具稳定感"。
- 触边停住时可有 1–2px 回弹，不做持续抖动。

### 7.3 碎砖

- 普通砖击碎：砖碎成 4–8 块同色系多边形碎块，径向短促迸出（初速外向、无重力或极弱重力），同时 100–150ms 白光闪后褪色消散；碎块继承砖色并带墨水边。
- 加固砖击碎：碎块更大更少（3–6 块）、钢灰色，迸出速度略快，另加 3–6 个短火花点；声音之外，"更硬"通过碎块尺寸与火花编码。
- 碎屑只做平面平移 + 淡出，不做旋转 3D 翻转；同一帧多砖同碎（GDD §5.2）时合并为一次闪光、碎屑总量设上限避免爆量。

### 7.4 加固砖受损（未碎）

- 被击瞬间砖体 2–3px 位移抖动（≤100ms）、内嵌板亮一次，随后**砖面常驻一条深色墨水位裂纹折线**并带一处缺角（§10）；迸 2–4 个小屑但不出现碎砖级爆裂。
- 受损反馈与"销毁"必须明确不同（GDD §9）：受损 = 砖还在 + 裂纹 + 小抖动；销毁 = 砖消失 + 碎块迸溅。二者在量级、寿命、残置物上全面拉开。

### 7.5 漏球

- 球越过底线瞬间（GDD §6.2）：球沿下落方向拉伸并淡出（150–200ms），底线虚玫瑰线瞬时变实亮 200ms，底部边缘一次玫瑰色暗角上涌；允许 60–100ms 的顿帧（hit-stop）强化失误感。
- 生命图标以"弹出 + 变空"回应（§10.3）。

### 7.6 结算与提示

- 胜利：场内静止（GDD §6.1），背景明度整体抬升一档，砖阵方向落下少量同色板的几何碎晶"彩屑"（600–900ms，限制在画面上部，不遮挡按钮）；分数做一次快速 count-up。
- 失败：场地饱和度下调（约 −40%）、四周玫瑰暗角缓慢脉动一次，不彩屑、不弹跳；节奏明显更沉。
- 暂停：场内瞬间冻结，场地缩至约 96–97%、压暗（`#0C0C1E` α55–65%），暂停面板浮起；恢复时反向。不做任何渐变式慢停（GDD §5.3 冻结语义）。
- 新纪录：结算数字变为强调金，一道金色短线从数字下标过，"新纪录"文字牌以 out-back 弹出，并在牌角迸 4–6 个金色小闪点；之后仅保留极轻微的周期高光流动，不闪烁刺眼。

所有动效必须尊重暂停冻结：暂停期间无任何背景/粒子动画继续播放。

## 8. 分层结构与横版适配

### 8.1 前后关系（后 → 前）

| 层 | 内容 | 透明/独立要求 |
|---|---|---|
| L0 背景渐变 | 深蓝纵向渐变，全屏 | 独立全幅层；允许裁切填满，不与场地绑定 |
| L1 背景微纹理 | 点阵/网格平铺 | 独立、可无缝平铺（tileable），α 3–6% |
| L2 远景装饰 | 低 α 大球/弧线母题 | 透明 PNG/矢量；只锚定在允许区域（§6.3） |
| L3 场地结构 | 三边微弱结构光、底线虚线 | 独立层；底线是唯一带语义的场地线条 |
| L4 砖阵 | 普通砖 / 加固砖 / 受损态 | 砖由 Scene 数据摆放；美术提供砖型，不在背景上烘焙砖影 |
| L5 主体 | 挡板、球 | 最高轮廓权重；球本体墨线任何情况下不透明 |
| L6 特效 | 闪光、碎屑、火花、拖尾 | 详见下方特效避让规则 |
| L7 HUD | 分数盒、生命组 | 常驻但克制；归 UI_UX_SPEC 定位 |
| L8 覆盖层 | 开始/暂停/胜利/失败面板、旋转提示页 | 自带压暗底；面板语言见 §12 |

### 8.2 特效避让规则（落实 GDD §9）

- 球与挡板的碰撞轮廓永远完整：其墨线与本体不被任何粒子以不透明形式覆盖；进入主体轮廓范围的粒子改从 L5 之后渲染或使用加色混合。
- 碰撞闪光只允许出现在碰撞点局部区域，禁止全屏白闪；全屏级明暗变化只允许在球已停止的胜负结算层出现。
- 单帧粒子总数有上限（由技术文档定额度），超限时优先保碰撞点反馈、削减远端余粒。

### 8.3 横版不同宽高比

- 仅横版（GDD §8）。**背景（L0/L1/L2）与场地（L3–L5）解耦**：背景负责填满任意横版画幅（渐变裁切 + 纹理平铺 + 装饰锚边），场地按比例缩放居中/锚定，二者不成烘焙合成图。
- L1 必须无缝平铺；L2 装饰只锚定四角/上沿安全区，不随宽度拉伸变形。
- HUD（L7）锚定边缘，信息盒之间允许随宽高比拉开间距，但不改变形状语言。
- 旋转提示页（GDD §8）沿用同一语言：居中一个"设备旋转中"的线稿图标（墨水线 + 单颗球母题）配中文提示，背景直接使用 L0，不另造风格。

## 9. 交互物与装饰的区分

- **场上唯一交互物是挡板**：胶囊形 + 最高饱和青 + 粗描边；砖阵全部静态（GDD §3.3），不出现"可点击砖"的错误 affordance（砖不做悬停态、不发光呼吸）。
- **UI 交互物（按钮）**：实色填充 + 墨水描边 + 圆角矩形，主按钮用强调金、墨水位文字；按下态用 1–2px 下沉/压暗表达。键鼠悬停态可有提亮，但因触控无悬停，任何信息不得只在悬停时出现。
- **装饰物**（L2 母题、背景纹理）：低 α、无描边或仅自身造型、绝无按下/悬停反馈。玩家应能仅凭"有无墨水实描边 + 实色填充"判断可交互性。
- Ready 呼吸的球不表现为"可点击物"，而是"等待发球"的状态物；发球提示以文字为准（UI_UX_SPEC 定义文案）。

## 10. 可辨识性规则（关键章节）

### 10.1 砖块三态冗余编码表

| 编码通道 | 普通砖 | 加固砖（完好） | 加固砖（受损） |
|---|---|---|---|
| 轮廓描边 | 3px | **5px（更重）** | 5px |
| 外形结构 | 单层圆角矩形 | **外框 + 内嵌冲压面板 + 角铆钉** | 同加固砖 |
| 饱和度/色相 | 高饱和糖果色（行序变色） | 低饱和钢灰蓝，不随行变色 | 钢灰蓝，明度再降约 10% |
| 表面纹理 | 仅顶高光 | 面板双线 + 铆钉 | **深色折线裂纹贯穿砖面 + 一处缺角** |
| 被击反馈 | 直接消失碎成多块 | 小抖 + 火花，不消失 | 直接消失，大块钢色碎块 |
| 分值暗示 | 不做视觉分值差 | 不做视觉分值差 | — |

三态在灰度截图下必须仍可分辨：普通砖无内板、加固砖有内板重边、受损态有裂纹缺角。**颜色差异只排第四位。**

### 10.2 主角（挡板/球）突出规则

- 三重冗余：形状（场上唯一胶囊 / 唯一正圆）、明度（球为全画面最亮）、色相（挡板唯一青、球唯一暖白）。
- 球的墨线 + 高光点在任何底色、任何 FX 背景上保持；光晕可弱化但本体不可"糊进背景"。
- 挡板与球之间也保持冷暖分离，Ready 时二者上下相邻也不混淆。

### 10.3 生命与分数的视觉表达

- **生命 = 与球同造型的小图标横排**：满生命为实心暖白小球（带墨线），失去后变为仅墨线的空心圈并降低 α，变化瞬间伴随一次弹出动画。生命只减不增（GDD §6.2），视觉上不出现"可获得生命"的加法语言。
- **分数 = 等宽数字置于圆角描边信息盒内**，实时更新不跳位；碎砖处允许浮现短寿命分值小字（主文字色、上浮 12–20px、≤280ms），其存在与否与密度上限由 UI_UX_SPEC/技术定，美术规则仅约束字形与寿命。
- 历史最高分在开始界面以次文字色常驻，与当前分数拉开层级；新纪录在结算时才允许金色待遇（§7.6、§11）。

### 10.4 小屏与远距尺度

- 按 GDD §8 的最小可用横版尺寸验收：所有砖态在该尺度下仍可辨。裂纹主线 ≥ 1.5–2 物理像素；铆钉在最小尺度若糊成一团则整体删除，仅保留"重描边 + 内板"编码加固砖、靠"裂纹 + 缺角"编码受损态。
- 数字与生命图标的最小尺度以"触控观看距离"为准（具体数值 UI_UX_SPEC 给出），美术保证其造型在缩到最小时不依赖细线细节。

## 11. 重要状态与过渡的视觉情绪一览

| 时刻（GDD 依据） | 情绪 | 视觉要点 |
|---|---|---|
| Ready 待发（§2.1、§3.2） | 蓄势、邀请 | 球呼吸脉动 + 光晕；发球提示文字在场；画面静态不喧哗 |
| 发球（§3.2） | 干脆启动 | 球沿出射向拉伸后回正；挡板轻闪；无爆发、无拖尾长光 |
| 普通砖破碎（§9） | 脆甜、奖励 | 同色 4–8 碎块短迸 + 局部白闪；可选分值浮字 |
| 加固砖受损（§9、§11 未决项的美术答复） | 硬碰、留下伤痕 | 砖体抖、面板亮、常驻裂纹与缺角、小火花；砖不消失 |
| 加固砖破碎（§9） | 更硬的破裂 | 少量大块钢灰碎块 + 火花，迸速略高于普通砖 |
| 漏球（§6.2） | 短促失误，不羞辱 | 球拉伸淡出、底线玫瑰实亮、边缘暗角、≤100ms 顿帧；生命图标变空 |
| 暂停（§6.4） | 时间凝固、安全 | 场地轻缩压暗、无运动残留；面板清晰给出口 |
| 胜利结算（§6.1） | 明亮、完成 | 背景提亮、几何彩屑、分数 count-up、新纪录金色提示（若有） |
| 失败结算（§6.2） | 安静、承认结果 | 场地去饱和、玫瑰暗角慢脉动、无彩屑；按钮语言不变 |
| 新纪录（§6.3） | 专属荣耀 | 金色数字 + 下划线扫过 + "新纪录"牌弹出 + 少量金闪点 |
| 再来一局（§2.2） | 快速重置 | 砖阵/分数/生命以 200–300ms 归位，不做长转场 |
| 返回开始界面（§6.4） | 退回"街机招牌" | 回到标题主视觉语言；此路径不写最高分（信息层面，不做特殊美术） |
| 竖版/空间不足（§8） | 礼貌等待 | L0 背景 + 旋转设备线稿图标 + 中文提示，无游戏元素误导 |

## 12. 跨界面一致性

开始界面、暂停层、胜负结算共享同一套视觉语法，只换情绪不换语言：

- **面板**：`#1B1D3D`（α 80–90%）圆角矩形 + 3px 墨水描边；主按钮 = 强调金圆角矩形 + 墨水边 + 墨水位文字；次级动作（返回开始界面等）使用透明底 + 3px 墨水/主文字描边的幽灵按钮。
- **标题**：任何界面的中文标题都用同一粗黑家族 + 描边挤出；结算标题（"通关"/"游戏结束"等具体文案 UI_UX_SPEC 定）靠情绪色与动效区分：胜利主文字色/金、失败玫瑰色，而非换字体。
- **母题延续**：开始界面主视觉的球与弧线，以角饰、分隔线、面板小图标的形式在结算层复用；开始界面的砖簇配色与场上砖完全一致。
- **层级不变**：结算面板出现时，场内是 L5 以下的静止画面（GDD §5.3、§6.1），面板永远在最上层且压暗底保证文字对比；不允许"结算标题直接压在砖阵上无衬底"的做法。
- 开始界面背景即游戏背景 L0–L2，玩家点"开始"进入场地时无风格跳变，只有场地与 HUD 淡入。

## 13. 资产生成 / 检索 / 程序化一致性标准

本节是给"无论走哪条生产路线"的统一交付契约；ASSET_PLAN 决定每件资产是手绘矢量、生成式产出、检索采购还是运行时程序化，本文不预设路线，也不要求概念图。

### 13.1 风格令牌（Style Tokens）

- 墨水：`#0F0F22`；描边档位 3 / 5px（裂纹 2–3px）；圆角连接；外/居中描边。
- 圆角：砖 = 砖高 14–18%；挡板 = 全胶囊；面板 = 高的 4–6%。
- 填充：平涂 + 纵向两档渐变（顶亮 8–10% L；挡板 15–20%）；顶内高光线 1px 白 α25–35%。
- 材质：哑光塑料 / 钢灰冲压件 / 上釉胶囊 / 自发光球芯；无照片纹理、无写实光影。
- 微纹理：仅背景，α 3–6%，无缝平铺。
- 细节预算：每物体一个要点；装饰低 α 无描边。
- 动效令牌：碰撞 80–120ms、碎屑 250–350ms、闪光 ≤150ms、界面 200–300ms；球位移恒速线性。

### 13.2 生成 / 检索关键词（风格约束语义）

适用方向描述（中文环境可双语检索）：扁平矢量街机、粗深色描边、圆角矩形、纵向柔和渐变、哑光塑料质感、高对比深蓝背景、友好敦实；排除语义：写实纹理、3D 渲染、照片、纤细线稿、水彩、赛博锐角、霓虹灯管写实光效。任何来源资产入库前按 §13.1 令牌逐项核对，并在"实际游戏缩放尺寸"下验收，不接受源图看着合格但场上不可读。

### 13.3 程序化规则

- 碎块：从被碎砖的填充色取色，形状为同砖圆角矩形的随机多边形分割，统一墨水边；生命周期与运动参数遵循 §7。
- 裂纹：在加固砖受损时于砖面内生成一条折线（2–4 个折点、墨水色、2–3px），必经一处边缘形成缺角；可由种子生成但样式范围固定，不得每次观感完全不同。
- 砖色行序、砖阵位置来自 Scene 数据（GDD §1.3），程序只换色不改形；任何程序变体不得越过 §10 的识别规则。

## 14. 禁止出现的视觉内容（排除项的视觉落实）

GDD §1.2 的排除项在视觉上同样不存在，任何界面（含开始界面主视觉、装饰、图标、动效）中：

- 不出现道具：无下落胶囊/字母图标、无激光、无多球、无加长挡板、无磁铁等任何增益图形；
- **任何画面永远只有一颗球**：标题主视觉也不得画多球、球群或"分身"暗示；
- 不出现多关卡/多模式暗示：无关卡地图、页码、模式徽章、难度选择 UI 残影；
- 不出现成长与解锁语言：无锁定图标、经验条、星星收集（新纪录用"文字牌 + 金色闪点"，不用解锁式星章阵列）、货币、奖杯柜；
- 无排行榜、账号、广告位、内购按钮、剧情文本与角色立绘；
- 不出现移动砖/特殊机制砖的视觉（无履带、无闪光砖、无问号砖）。

如某装饰创意与上述条目图形上可能混淆，优先删除。

## 15. 验收检查（美术侧）

1. 游戏内任意时刻截图：球是明度最高点且墨线完整；挡板是唯一胶囊与唯一青色；遮挡判断清晰（GDD §9）。
2. 灰度截图：普通砖 / 加固砖 / 受损加固砖三态可辨；满/空生命可辨。
3. 红绿色盲模拟下玩法信息无丢失。
4. 在 GDD §8 最小可用横版尺寸实机/模拟器查看：裂纹、铆钉取舍、HUD 数字与生命图标均不糊。
5. 运动中观察：碰撞挤压在 120ms 内回正；碎屑 350ms 内退场；暂停瞬间一切冻结；多砖同帧不出现爆量闪光。
6. 开始 → 游戏 → 暂停 → 胜负结算：无风格跳变，面板/按钮/标题同族。
7. 竖版提示页与全界面巡查：§14 所列禁止图形零出现。
8. 静态源图合格不等于通过；最终以实际游玩画面为准。当前批次无法运行游戏时，"运行时可读性"标记为未验证，由后续合并批次补验。
