## 1. 目的与范围

把 GDD 的六个游戏状态（开始界面 / 发球准备 / 游玩中 / 已暂停 / 过关结算 / 失败结算）落成**可编辑的 UI 数据**：屏幕/HUD 文档、共享组件、区域分配、文案、焦点顺序、状态样式与适配行为。

- 最终可编辑输入位于 `content/ui/`（schema `beegame-content.v1`，闭集 role，取自 `uiVocabulary.roles`），是 UI 层级与布局的唯一可编辑来源；运行时按 `TECHNICAL_DESIGN` 第 4 节消费。
- 本文件只覆盖 GDD 已确立的界面与操作：**不新增平台、不新增玩法**。不重定义输入事件（意图归一面以 GDD 操作表与 TECH 7.1 为准）。
- 本批次未观测任何运行时；几何结论来自空间计算器，文字/视觉/渲染项均标注"未验证"。

### 1.1 UI 文案决策（本文件拍板）

| 决策 | 取值 | 说明 |
|---|---|---|
| 游戏名称 | **霓虹打砖块 NEON BREAKOUT** | 简报未给游戏名；UI 文案决策，街机机柜感，与 ART 灯箱招牌/灯管字一致 |
| 分数显示 | 5 位补零等宽数字（`00000`） | 容纳上限 2100（BALANCE 3.4），机柜计字转轮感 |
| 发球提示 | 空格 / 点按发球 | 键盘与触屏同一文案 |

## 2. 根字段定值（全部 UI 文档一致）

| 根字段 | 定值 | 依据 |
|---|---|---|
| `data.orientation` | `"Landscape"` | GDD 第 8 节，仅横屏 |
| `data.referenceResolution` | `[1280, 720]` | 与场景参考框一致（LEVEL 3、ART 参考画布） |
| `data.targetViewports` | `[[1280,720],[1024,576],[960,540]]` | 参考尺寸 + 过渡尺寸 + 最小支持尺寸；**只列横屏** |
| `data.minimumControlSize` | `[88, 44]` | 最终宿主逻辑像素下的控件最小宽×高；触屏手指目标取向（横向宽目标），非平台常量 |
| `data.compactMaxWidth` | `1024` | viewport 宽 ≤1024 应用 compact 变体；由容器所需空间决定 |

**最小可用设计尺寸：960 × 540（横屏）。** 低于该尺寸的横屏宿主显示"空间不足"提示，不压缩游戏；竖屏宿主显示旋转提示（GDD 8）。

## 3. 共享设计系统（组件只定义一次）

以下 token 与区域分配在本文件**定义一次**；各 JSON 中的 `style` 是其解析实例（节点 `data.component` / `data.variant` 标注 token 名），运行时按同名消费，不逐屏发明样式。

### 3.1 覆盖层页面布局（overlay-page）：区域分配

所有覆盖面板（暂停 / 过关 / 失败 / 加载失败）共用同一区域模型，各屏只提供内容与尺寸差异：

```
┌──────────── panel（圆角 8，深色底，青色描边+外发光）────────────┐
│  padding [top,right,bottom,left]；column，align center          │
│  ① 标题区：固定行高，居中、大字、主文字色（唯一灯管外的大字焦点） │
│  ② 内容区：固定/弹性高度——提示小字、分数块（label+数字）、pip 行  │
│  ③ 按钮区：纵向 column、统一按钮宽=内宽、高 48、gap 10           │
└──────────────────────────────────────────────────────────────┘
```

| 区域 | 参考档（宽 >1024） | compact（宽 ≤1024） | 各屏差异 |
|---|---|---|---|
| panel | 宽 440；padding [28,32,28,32]；column gap 16 | 宽 400（错误面板 380）；padding [24,24,24,24]；gap 14 | 暂停高 340；结算高 400；错误高 280 |
| 标题区 | 行高 40，标题 28–32 px | 同 | 文案不同；失败标题不用红色（3.4） |
| 内容区 | 宽=内宽（376） | 352（错误 332） | 暂停：一行按键提示；结算：分数块；失败：分数块+全空心 pip；错误：说明+可选错误文案 |
| 按钮区 | 按钮 [内宽,48]，gap 10 | 同（按钮高恒 48 ≥ 44） | 按钮数量：暂停 3、结算 2、错误 1 |

- 面板在遮罩内以 `middle-center` 锚定（固定尺寸，不做拉伸锚点）；遮罩以 `anchorMin [0,0]` / `anchorMax [1,1]` 全屏压暗。
- **不足空间行为**：高度不足时压缩内容区内边距与 gap（compact 档已给定值），按钮高 48 与字号不缩；任何情况下不裁文字、不移除按钮。

### 3.2 霓虹按钮（neon-button）：主/次两档 + 状态

| 档位 | 默认态（default） | 用途 |
|---|---|---|
| primary | 底 `#123244`/90%，2px `#2DE2FF` 描边，文字 `#E8F4FF`，外发光 8/40%，圆角 8 | 开始游戏、继续、重新开始、重试 |
| secondary | 底 `#101830`/85%，2px `#5E72A8` 描边，文字 `#B9C6E8`，发光 4/20% | 返回开始界面（暂停界面另含一个 secondary 重开） |

按钮交互状态（两档共用规则；颜色/发光取自 ART 3.4 与第 11 节）：

| 状态 | 表现 | 触发 |
|---|---|---|
| default | 如上 | 未聚焦 |
| focused（键盘焦点） | 主强调描边提亮、外发光升至 8/55%，内顶部加一条 1–2px 高光；secondary 聚焦时描边变 `#2DE2FF` | Tab / 进入界面时默认焦点 |
| pressed | 缩放至 0.98、亮度上提、发光收紧闪一下（≤120ms） | Enter / Space / 点按按下 |
| disabled | 描边 `#4A5480`、文字 `#7B88B8`、关闭发光；整棵子树抑制 | 首版按钮常态均可用；保留定义给加载/异步门控 |
| error（仅重试按钮） | 一次 `#FF3B4D` 描边脉冲（约 260ms）并显示错误文案；危险色必伴随形状/运动（ART 3.4） | 重试再次失败 |

键盘焦点：进入覆盖界面时焦点落在默认主按钮（GDD 操作表允许键盘确认）；Tab 顺序见各屏；**Enter / Space 激活聚焦按钮**，长按不连发；键盘确认与点按只产生一次激活（AUDIO A-08）。

### 3.3 共享表现组件

| token | 定义（参考尺寸） | 资源/字体 |
|---|---|---|
| neon-panel | 底 `#0C0A20`/94%，2px `#2DE2FF` 描边（半径 8），弱外发光 4/25% | 视觉用途移交 ASSET_PLAN；当前为程序化样式 |

## 4. 界面规格（逐屏）

### S1 开始界面（Menu）

- **进入条件**：页面加载完成、startup 资源可用后首先进入（GDD 5.1）。**退出条件**：激活"开始游戏" → 生命/分数重置（3 / 0）→ 发球准备。
- **信息层级**：① 灯箱招牌标题"霓虹打砖块 NEON BREAKOUT"（上部 12%–32% 区，第一焦点，灯管字）+ 右侧大号暖白球（第二视觉点）；② 居中"开始游戏"主按钮（安静区，纵向约 55%）；③ 按钮下方一行操作小字（次要）。
- **元素**：`marquee`（title-text / subtitle-text / light-strip 6 段）、`hero-ball`、`start-button`、`start-hint`。
- **文案**：
  - 标题：霓虹打砖块；副题：NEON BREAKOUT（游戏名为 1.1 节 UI 文案决策）
  - 按钮：开始游戏
  - 小字：Enter / 空格 开始游戏 · 方向键或 A/D 移动挡板
- **内容来源**：标题/小字为静态文案；本屏无动态数据（首版无最高分等持久化内容，GDD 2.2）。
- **动作与结果**：
  - 开始游戏（按钮 / Enter / Space / 点按）：在用户手势处理中调用 `audio.unlock()`（AUDIO 8.2 接口），解锁成功/失败均进入发球准备；失败不阻塞（无声可玩）。音效：`ui.click`。
- **状态**：默认焦点 = 开始按钮；按钮 default/focused/pressed/disabled 按 3.2；无错误态。compact 见第 5 节（隐藏 hero-ball、字号下调）。

### S2 游玩 HUD（Ready / Playing 常驻）

- **进入条件**：进入发球准备时挂载，Ready / Playing / 失误过渡期间常驻；**退出条件**：进入暂停或结算时由覆盖层取代（暂停/结算覆盖层只在相应状态出现）。
- **信息层级**：① SCORE 左簇（标签 + 5 位等宽数字）；② 右侧簇：LIVES（标签 + 3 pip）与暂停按钮。HUD 冷静常驻、不抢球（ART 7）。
- **文案**：标签 SCORE、LIVES；分数补零显示如 `00000`；无其他文字。
- **内容来源（绑定）**：
  - `score-value` ← `session.score`，格式 `00000`，范围 0–2100，5 位；
  - `pip-1/2/3` ← `session.lives`：序号 ≤ 当前生命 = alive 样式，否则 lost 样式；原地换形不重排（ART 8）。
- **动作与结果**：暂停按钮 → `pauseToggle` 意图（Playing 才生效，GDD 5.1），音效 `ui.click`；P/Esc 等价。
- **状态**：暂停按钮为 icon 图形按钮，命中区 88×44；HUD 不显示重开/退出（GDD 5.2）。分数与生命的变化即状态反馈（数字滚动/换形），无独立 toast。

### S3 发球准备提示（Ready 提示，HUD 文档内节点）

- **进入条件**：状态 = Ready（新开局或失误后仍有生命）。**退出条件**：发球生效（→ Playing）立即隐藏。
- **信息层级**：球与挡板关系是第一阅读（世界层）；场内中下部呼吸提示是唯一场内文字，引导发球动作。
- **元素 / 文案**：`serve-zone`（透明按钮命中区）+ 子文本 `serve-prompt`："空格 / 点按发球"。
- **内容来源**：静态文案；可见性绑定 `enabledWhen: state===ready`。
- **动作与结果**：点击/点按热区或按空格（由输入层归一的 `serve()`）→ 发球，音效 `ball.launch`；仅 Ready 接受，不连发（GDD 6.3、AUDIO A-01）。
- **状态**：提示做 1.2s 周期呼吸（不透明度 0.55↔1、缩放 0.97↔1.03，ease-in-out；ART 8），是全场唯一被允许的循环呼吸。

### S4 已暂停覆盖层（Paused）

- **进入条件**：Playing 中暂停输入（按钮 / P / Esc）；进入瞬间运动冻结（GDD 6.3）。**退出条件**：继续 → 原样恢复 Playing（位置/速度不变）；重新开始 → 初始 Ready；返回开始界面 → Menu。
- **信息层级**：① 标题"已暂停"；② 一行按键提示（次要信息）；③ 按钮区：继续（primary，默认焦点）、重新开始（secondary）、返回开始界面（secondary）。
- **文案**：已暂停；P / Esc 继续 · Tab 切换按钮；继续；重新开始；返回开始界面。
- **内容来源**：静态；冻结局面由世界层定格，本层不重复呈现分数。
- **动作与结果**：继续 → resume（`game.resume`），不补发暂停期间输入/声音；重新开始 → restart；返回 → exitToMenu。按钮音效均为 `ui.click`。
- **状态**：焦点 Tab 顺序 1 继续 → 2 重新开始 → 3 返回开始界面，循环；遮罩 `#060512`/58% + 轻微去饱和。

### S5 过关结算（LevelClear）

- **进入条件**：最后一块砖被击碎（含 GDD 6.2 同帧碎砖优先）；球停止。**退出条件**：重新开始 → 新开局 Ready；返回开始界面 → Menu。
- **信息层级**：① 标题"过关！"；② 本局得分（label + 大号等宽数字，第二焦点）与击碎计数；③ 按钮区：重新开始（primary，默认焦点）、返回开始界面（secondary）。
- **文案**：过关！；本局得分；击碎砖块 60 / 60（绑定模板）；重新开始；返回开始界面。
- **内容来源**：final-score-value ← `session.score`（`00000`，0–2100）；bricks-count ← `session.bricksBroken`（模板 `击碎砖块 {value} / 60`）。
- **动作与结果**：restart / exitToMenu，音效 `ui.click`；进入时世界侧播放 `game.win`，按钮在光效中即可点（ART 6）。
- **状态**：Tab 1 重新开始 → 2 返回；进入过渡期间（绽放 0.8–1.2s）按钮已可激活；无禁用态。

### S6 失败结算（GameOver）

- **进入条件**：最后一条生命随落底失去（`game.over` 取代 `life.lost`，不叠加）。**退出条件**：同 S5。
- **信息层级**：① 标题"游戏失败"（主文字色，**不使用红色**）；② 本局得分 + 一行 3 个全空心 pip（形状承载"生命耗尽"，危险色规则 ART 3.4）；③ 重新开始（primary，默认焦点）、返回开始界面（secondary）。
- **文案**：游戏失败；本局得分；重新开始；返回开始界面。无"生命已耗尽"文字——由全空心 pip 形状表达（关键信息去色后仍可辨）。
- **内容来源**：final-score-value ← `session.score`；lost-pips 为静态全空心 life-pip（lost 样式）。
- **动作与结果**：restart / exitToMenu，音效 `ui.click`。
- **状态**：Tab 顺序同 S5；进入时世界侧暗下过渡，面板保持按钮最低对比。

### S7 横屏旋转提示（竖屏宿主消息）

- **进入条件**：视口 height > width。**退出条件**：旋转回横屏后自动消失并继续原有流程；无按钮、非阻塞。
- **信息层级**：① 设备轮廓图标（青色描边）；② "请旋转设备至横屏"；③ "旋转后将自动继续"（次要）。
- **文案**：请旋转设备至横屏；旋转后将自动继续。
- **内容来源 / 动作**：静态消息；不提供任何操作（避免误操作），无音效。
- **状态**：无控件状态。竖屏几何用草稿尺寸临时探查（414×896、360×640，见第 7 节），`targetViewports` 依第 2 节只列横屏。

### S8 空间不足提示（横屏但低于最小尺寸）

- **进入条件**：横屏但视口低于最小支持（任一维度不足 960×540）。**退出条件**：放大窗口/调整缩放恢复到 ≥960×540 后自动消失。
- **信息层级**：① "空间不足，请放大窗口"；② 解决方法（次要）；③ 最小尺寸等宽数字行。
- **文案**：空间不足，请放大窗口；也可尝试减小浏览器页面缩放比例；最小尺寸 960 × 540（横屏）。
- **内容来源 / 动作**：静态消息，无按钮、无音效；不允许把游戏压缩到不可操作（GDD 8）。
- **状态**：无控件状态；几何探查 800×450、900×500（第 7 节）。

### S9 加载视图（startup）

- **进入条件**：页面开始加载 startup 文档/资源。**退出条件**：startup 完成 → 开始界面；失败 → S10。
- **信息层级**：① 安静的小字 wordmark NEON BREAKOUT；② 加载指示环（焦点）；③ "加载中…"。
- **文案**：NEON BREAKOUT；加载中…。无进度百分比（不确定进度，不伪造数值）。
- **内容来源 / 动作**：系统加载状态；无按钮、无音效（解锁前保持安静，AUDIO 8.2）。
- **状态**：指示环旋转循环；尊重 reduced-motion（第 6 节）。

### S10 加载失败 / 错误恢复视图

- **进入条件**：startup 或 on-demand 加载失败、资源缺失（TECH 5.2 显式错误，不静默回退内置图形）。**退出条件**：重试成功 → 回到加载目标流程（默认开始界面）。
- **信息层级**：① 标题"加载失败"；② 说明文案；③ 可选错误细节行（默认不显示）；④ "重试"按钮（primary，默认焦点，**恢复路径恒在，永不移除**）。
- **文案**：加载失败；资源加载未完成，请检查网络后重试。；重试失败，请再次尝试（错误态）；重试。
- **内容来源**：`retry-detail` 绑定 `enabledWhen: lastRetryFailed===true`（默认 enabled=false）。
- **动作与结果**：重试 → `retryLoading`（重新执行加载管线），音效 `ui.click`；再次失败 → 显示错误细节 + 按钮 error 脉冲，可无限重试。
- **状态**：错误细节出现时按钮给出 `#FF3B4D` 描边一次脉冲（形状+运动，ART 3.4）；Tab 仅一个焦点，Enter/Space 重试。

## 5. 适配行为（单一策略）

从参考 1280×720 到最小 960×540，采用**"固定结构 + 容器间距收缩 + compact 变体"**，不做整体等比缩放：

1. **HUD 顶带**：高度恒为 48（宿主逻辑像素），横向随根拉伸；不随视口缩放而变矮。
2. **覆盖面板**：固定尺寸锚定居中；宽度只在两档间切换（标准 440 / compact 400，错误面板 380），按容器 padding/gap 的档级收缩间距；**按钮高恒 48、宽=面板内宽，任何尺寸 ≥ minimumControlSize [88,44]**。不允许整体等比缩到不可操作，不允许裁切文字。
3. **文字**：字号按档级下调（如标题 56→46、HUD 数字 24→20），文本框宽度按 compact 尺寸给定；不依赖运行时自动缩字（`uiLayoutContract.textFit`），最终 fit 在真实字库加载后测量（未验证）。
4. **世界层**：与 UI 适配相互独立，相机 keep-height 取景（LEVEL 5）；UI 不因世界缩放重排。

### 5.1 compact 变体（viewport 宽 ≤ 1024；含 1024×576、960×540）

| 对象 | compact 调整 |
|---|---|
| 开始界面 | 标题 56→46、副题 20→17；灯带 10→8 高、段宽 56→48；**隐藏 hero-ball 大号球（enabled=false）**；开始按钮 260×56→240×52；小字 14→13 |
| HUD | SCORE 簇左边距 24→16、字号 14/24→12/20；右侧簇间距 16→12，pip 18→16；**暂停按钮保持 88×44 不缩** |

## 6. 动作与过渡反馈

| 触发 | 视觉反馈 | 时长/参数（ART 6、8） | 音频事件（AUDIO_DESIGN） |
|---|---|---|---|
| Ready 发球提示 | 呼吸（唯一循环） | 1.2s，不透明度 0.55↔1、缩放 0.97↔1.03 | 无（可选 O-01 待机滴答，首版不做） |

| 暂停继续 | 遮罩移除，原样恢复 | 150–200ms | `game.resume`、`ui.click` |
| 失误（仍有生命） | 克制屏闪：暗角一次红脉冲（`#FF3B4D`）；单次衰减屏震；球向底部暗去 | 屏闪约 260ms；屏震约 300ms、振幅 ≤ 设计高度 0.8% | `life.lost` |
| 过关 | 明亮绽放：碎点暖白金径向光（峰值白约 50%）、少量火花，随后亮一档的结算画面 | 0.8–1.2s | 单次碎砖组音 + `game.win`；底乐淡出 |
| 失败 | 暗下：暗角收拢、抽除饱和、冷青发光逐档变暗，保留面板最低对比 | 0.8–1.2s | `game.over`（取代 life.lost）；底乐淡出 |
| 按钮激活 | 按下缩放/亮度；focused 焦点环 | ≤120ms | `ui.click` |
| 重试再次失败 | 按钮危险色描边一次脉冲 + 错误文案 | 约 260ms | `ui.click` |

### 6.1 reduced-motion（CSS `prefers-reduced-motion` 取向）

检测到减少动态偏好时，上述运动改为**静态版本**：

- 关闭发球呼吸的缩放，仅保留不透明度微调（或完全静态）；
- 失误：关闭屏震与红脉冲，改为失误线/生命 pip 的静态形状变化（红色仍只伴随形状）；
- 过关/失败：关闭绽放/暗下动画与火花，直接呈现结算面板的静态明暗档；
- 加载环：改为静态等宽文字"加载中…"或静态环，不旋转；
- 暂停/继续过渡：无动画切换。

关键信息（生命、分数、结果）在静态版与无声状态下均完整可读——音频不单独承载关键信息（AUDIO 9）。
