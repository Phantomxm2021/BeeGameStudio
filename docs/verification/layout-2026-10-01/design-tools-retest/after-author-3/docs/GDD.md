# 游戏设计文档（GDD）——打砖块（首版）

- 版本：v0.1（作者批次 1/5 初稿）
- 作者：主 Agent（玩法系统设计）
- 日期：2026-10-01
- 文档语言：中文；游戏内玩家可见文字：中文

## 1. 概述

一款经典街机风格的 2D 打砖块游戏。玩家横向移动底部挡板，反弹一颗不断运动的球，击碎场上全部砖块即过关；球落出底部则失去一条生命，生命耗尽即失败。

- 平台：Web 浏览器（React，2D）
- 屏幕方向：**仅横屏（Landscape）**
- 输入：键盘 / 鼠标、触屏
- 美术基调：风格化（Stylized）街机表现
- 首版目标：一个完整、可重复游玩的核心循环，含 **1 个关卡** 的代表性内容

## 2. 首版范围

### 2.1 首版必含内容

- 一块由玩家控制的横向挡板。
- 一颗持续运动、与边界 / 挡板 / 砖块弹射的球。
- 一个固定布局的砖块阵列（单一阵列、单一关卡）；普通砖块被球击中一次即被击碎。
- 三条生命的失误惩罚；本关分数与击碎砖块计数。
- 完整的开始 → 游玩 → 过关 / 失败 → 重开 / 退出流程。
- 键盘、鼠标、触屏三类输入均可完成全部操作。
- 暂停与继续。
- 横屏方向与最小可用尺寸的提示信息（见第 8 节）。

### 2.2 明确排除项（首版不做）

- 多关卡、关卡选择、关卡解锁与进度保存。
- 多种游戏模式、无尽模式、排行榜、联网功能。
- 道具掉落（多球、加长挡板、激光等）、特殊砖块（多血、移动、爆炸砖块等）。
- 球速随进程加快以外的任何成长 / 经济 / 养成系统。
- 最高分等跨会话持久化：首版分数仅存在于当前游戏会话，刷新页面后清零。

> 以上排除项中的任何内容若后续被要求加入，属设计变更，须先修订本 GDD 再落地。

## 3. 玩家目标与核心循环

**目标：** 在生命耗尽之前，击碎场上的全部砖块。

**核心循环（单次发球内）：**

1. 玩家左右移动挡板，预判球的落点。
2. 球撞击挡板后反弹回场上；撞击位置（挡板中点偏左还是偏右）决定反弹角度，给玩家控制方向的手段。
3. 球击中砖块：砖块被击碎，分数增加，球反弹。
4. 球若越过挡板落出场地底部：失去一条生命，重新摆位发球；若仍有生命，循环继续。
5. 场上砖块全部被击碎 → 过关。

**挑战与反馈：** 挑战来自对球轨迹的持续预判与挡板到位精度；反馈为击碎砖块的即时视觉 / 听觉响应、分数增长、以及挡板反弹角度控制带来的"接球手感"。具体球速、挡板宽度、砖块阵列规模、生命数、分值等可调数值统一由《数值平衡文档》 authoritative 定义，本文档不重复维护参数表。

## 4. 操作

| 操作 | 键盘 / 鼠标 | 触屏 |
|---|---|---|
| 移动挡板 | 键盘左右方向键（或 A/D）按住持续移动；鼠标在场地内横向移动时挡板跟随光标横坐标 | 手指在场地（含挡板区域）横向拖动 / 按住拖动，挡板跟随触点横坐标 |
| 发球 | 准备状态下按空格键，或点击 / 点按场地内"发球"提示区域 | 同点击：点按场地发球 |
| 暂停 / 继续 | 暂停按钮或 P 键 / Esc | 暂停按钮 |
| 重开本关 | 结算界面上的"重新开始"按钮（键盘可聚焦确认） | 同按钮点按 |
| 退出 | 暂停或结算界面上的"返回开始界面"按钮 | 同按钮点按 |

操作规则：

- 挡板只能横向移动，始终被限制在场地左右边界内，不会移出屏幕。
- 挡板的纵向位置固定。
- 鼠标 / 触屏采用"横坐标跟随"，不要求指针精确位于挡板上，降低操作门槛。
- 同时存在多个输入设备时，以最近一次产生有效输入的设备为准，结果上只表现为挡板移动到对应位置，设备切换无额外状态。

## 5. 游戏状态与流转

### 5.1 状态定义

1. **开始界面（Menu）**
   - 进入条件：页面加载完成、资源可用后首先进入。
   - 可用操作：查看"开始游戏"；通过键盘确认、鼠标点击或触屏点按开始。
   - 流向：开始游戏 → 进入"发球准备"，生命数与分数重置为首版初始值（见平衡文档）。

2. **发球准备（Ready）**
   - 进入条件：从开始界面新开局；或游玩中失去一条生命后仍有剩余生命。
   - 表现：球静止附着（摆位）在挡板上方，砖块阵列恢复为本关应有的状态——新开局时为完整阵列；失误后重发时，已击碎的砖块保持被击碎，不恢复。
   - 可用操作：移动挡板（球随挡板横向摆位）；执行发球。
   - 流向：发球 → 游玩中。停留本状态不计时、不扣生命。

3. **游玩中（Playing）**
   - 进入条件：发球输入生效，球离板开始运动。
   - 可用操作：移动挡板；暂停。
   - 流向：
     - 球落出底部且仍有生命 → 生命数 −1 → 发球准备；
     - 球落出底部且生命归零 → 失败结算；
     - 最后一块砖块被击碎的同一时刻起，游玩结束 → 过关结算（判定优先级见第 6 节）；
     - 暂停输入 → 已暂停。

4. **已暂停（Paused）**
   - 进入条件：仅在游玩中可进入。
   - 表现：球与全部运动停止；显示继续、重新开始、返回开始界面。
   - 流向：继续 → 回到游玩中，从停止处原样恢复（球位置、速度方向不变）；重新开始 → 以初始生命与分数重新进入发球准备；返回开始界面 → 开始界面。

5. **过关结算（LevelClear）**
   - 进入条件：场上最后一块砖块被击碎（首版只有一关，即等同全部通关）。
   - 表现：球停止，展示通关信息与本局分数。
   - 可用操作：重新开始、返回开始界面。
   - 流向：重新开始 → 新开局（完整阵列、初始生命与分数）；返回 → 开始界面。

6. **失败结算（GameOver）**
   - 进入条件：球落出底部且失误前生命已为最后一条。
   - 表现：展示失败信息与本局分数。
   - 可用操作：重新开始、返回开始界面。
   - 流向：同过关结算。

### 5.2 流转通则

- 结算界面（过关 / 失败）与暂停界面中，挡板移动键不产生移动；游玩中"重开 / 退出"按钮不可见，必须先暂停或结算。
- 任何状态下刷新页面都回到开始界面，本局进度不保留（首版无持久化）。
- 重复游玩之间无差异：重开即完整重置，不存在难度继承、解锁内容或随机性规则差异（砖块布局固定）。

## 6. 系统交互与判定规则

本节只定义玩家可观察的规则结果，不规定实现算法。

### 6.1 球的运动与弹射

- 发球后球持续运动，不在无碰撞时停止或减速。
- 球与场地左、右、上边界碰撞后按弹射改变方向；场地底部不弹射，越过底部即计为失误。
- 球与挡板碰撞后向上反弹：击中挡板中点附近接近垂直反弹，越靠近挡板侧边，反弹角度越大（左右方向与所击一侧一致）。球在挡板上不会向下穿过挡板。
- 球与砖块碰撞后砖块按其规则处理（首版：被击碎），球反弹离开。
- 球的基础速度以及随击碎数量 / 时间允许的提速档位由平衡文档定义；提速在达到阈值后立即生效，不影响球当前所在位置。

### 6.2 同时性与先后判定

当同一帧 / 同一时刻出现多个结果时，按下列玩家可观察的优先级处理：

1. **最后一块砖与失误同时发生：** 若一次碰撞既击碎了最后一块砖块、球又将越过底部，以"击碎砖块"结算，即判定过关，不因该球随后落底而再扣生命。依据：过关条件先于同次运动的失误成立。
2. **一球同时触及多块砖块：** 所有被触及的砖块均被击碎并计入总分，球只产生一次反弹方向变化；若这些砖块中包含最后一块，按过关处理。
3. **球同时触及砖块与边界 / 挡板：** 砖块击碎与相应反弹均生效，反弹结果以挡板反弹规则优先（球不会因此向下落）。
4. **生命扣减只在失误成立时发生一次：** 一次落底不重复扣减；落底后球立即停止，不再与场上物体交互。

### 6.3 过渡期间的输入

- 发球准备期间的挡板移动生效并带动球的摆位；在发球输入生效前，球不离开挡板。
- 暂停、结算的进入瞬间，正在进行的运动即刻冻结；过渡动画 / 界面出现期间的挡板移动输入不产生位移，发球输入不产生新球。
- 从暂停恢复时，恢复瞬间之后的输入才生效，不补发暂停期间积压的移动。

### 6.4 分数与计数

- 每击碎一块砖块得分；不同外观（颜色行）的砖块可对应不同分值，具体分值由平衡文档定义。
- 分数只增不减；失误不扣分，只扣生命。
- HUD 在游玩与准备状态下持续显示当前分数、剩余生命数；结算界面显示本局最终分数。

## 7. 首版关卡内容

- 唯一关卡：场地上部排列一个固定的矩形砖块阵列，行列数、砖块尺寸、间距与边距由平衡文档给值，并在场景数据（Scene JSON）中作为摆位的可编辑来源。
- 阵列中全部为一击即碎的普通砖块；可通过颜色区分行并对应不同分值，但行为完全相同。
- 关卡不随游玩次数变化。

## 8. 画面方向、尺寸与数据约定

- 游戏**只支持横屏**。竖屏（或窗口宽高比呈竖向）时不做重排，显示"请旋转设备至横屏"提示。
- 横屏下视口短边或可用空间小于最小可用尺寸时，显示"空间不足，请放大窗口"提示，不允许把游戏压缩到不可操作的尺寸。最小可用设计尺寸（设计坐标系下的宽 / 高）由 UI/UX 文档结合本文档的横屏约定定义。
- 场景层级、挡板 / 砖块 / 球的初始摆位、UI 布局、响应式变体与资源绑定以**作者编写的 Scene/UI JSON 为唯一可编辑来源**；运行时代码加载该数据实现玩法，不以代码常量取代这些作者决策。文档中的尺寸为设计坐标，而非宿主设备的固定像素。

## 9. 完成条件（可在游玩中观察）

首版视为完成，当且仅当以下情形均可在实际游玩中观察到：

1. 加载后进入开始界面，并能开始一局新游戏。
2. 键盘、鼠标、触屏均能横向移动挡板并完成发球。
3. 球正确地与边界、挡板、砖块弹射；挡板击球位置改变反弹方向。
4. 击碎砖块时砖块消失、分数增加；最后一块砖块被击碎后进入过关结算。
5. 球落出底部时扣除一条生命并回到发球准备，已击碎砖块不恢复；最后一条生命失去后进入失败结算。
6. 暂停可冻结局面并原样继续；结算与暂停界面可重开本局或返回开始界面。
7. 竖屏 / 空间不足时显示对应提示而非错误布局。
8. 重开后分数、生命、砖块阵列完整重置。
