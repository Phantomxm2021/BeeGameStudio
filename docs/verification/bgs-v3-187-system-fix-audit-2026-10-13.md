# 资源查询与 UI 探针坐标域：实施前审计

范围：只修 BGS 接口/验证机制，不改游戏、正式 frontend、Claude Code 或 Agent 技术选择；不付费运行，成本优化后置。

## 已证实根因

- 资源 CLI 将全部 JSON 放进 filters，服务端选择已知字段后丢弃未知字段；query、拼错键及错误类型能退化为全库浏览。分页 limit/cursor 没有正常 CLI 传递路径。
- UI prepare 按窗口 viewport 解算，浏览器取得窗口 CSS 像素；固定逻辑画布经过根容器缩放时，源坐标与观测不在同一坐标域。

## 方案及审计结论

1. 资源 CLI 支持现有平铺 filters、加分页的平铺写法以及服务端原生 {filters,limit,cursor}。未知键和错误类型在请求前报错；服务端也独立验证，避免其他调用绕过 CLI。错误列出合法字段/格式；不添加文本搜索或自动猜参数。合法旧调用不变，错误旧调用从静默成功变明确失败，属于必要兼容行为变更。
2. UI 只增加可选 coordinateRoot（CSS selector）。逻辑 viewport 取保存的 referenceResolution/根 size，不由 Agent 传期望坐标；所选 DOM 根必须是被测元素的严格祖先，未变形布局尺寸与源尺寸一致，且仅支持轴对齐正向缩放/平移。将实际目标框换回逻辑坐标，保留窗口框和映射事实。
3. 不选参考根的旧探针继续按窗口坐标工作；不自动侦测游戏架构或要求引入某个 renderer。字体、像素、音频驱动不扩张其既定能力。参考根不能用于像素/音频输入；字体检查明确不接受该几何选项。
4. 从独立根取得映射，而非从被测框拟合；根在基线/扰动/还原间变化、旋转/倾斜/透视、隐藏或尺寸来源不足时未验证。节点偏移错误、忽略 position/size、实际文本溢出仍失败；不删除失败反例来追求 PASS。
5. UI 检查版本提升，旧收据不能自动提升为新证据；不自动测量、重试或续作。预期副作用：涉及旧检查的证据需按正常授权重新核对，不改写原回执。

## 回归要求

- CLI/API：合法旧 filters、原生请求、分页第二页、空筛选；未知/错误位置/错误类型明确失败，失败调用不访问资源库。Pack 与 elements 都覆盖。
- UI：窗口直接布局、960/非同比例窗口内等比信盒/轴对齐缩放、偏移根、扰动与还原；忽略值、坐标公式错误仍失败；坏根/尺寸/旋转/参照变化未验证；动态文本溢出仍失败。
- 使用独立合成临时工程、现有检查链与专用测试 Chromium，不读写磁轨调度以外的付费工程。补类型检查、相关测量/版本回归，检查本轮 diff；最后核对磁轨调度原文件未变。

结论：可实施。新增的是必要的检查输入/事实校验，不是业务阶段或引擎框架；不能据此承诺整体游戏品质合格。

## 落地与复核结果

- [x] 资源 CLI 支持平铺旧筛选及原生请求结构，分页正常透传；帮助中列出结构化字段、不支持文本 query/search、limit/cursor 位置。未知键/类型/多余位置参数不访问服务。API Pack 与 elements 路由独立拒绝未知/错类型参数，返回400和具体字段；正确调用与游标绑定保持。
- [x] UI 输入新增可选 coordinateRoot；预期由保存的 referenceResolution/root size 解算。浏览器只从被测元素的严格祖先测参考尺寸，验证与来源相符、无 padding/border、正向轴对齐变换且可见。输出保留窗口 bounds、逻辑 bounds、scale 与 offset，失败时不将窗口框伪标为逻辑框。
- [x] 基线/扰动/还原中参考根必须稳定。缺根、错误选择器、自引用、不相干根、旋转/透视、尺寸冲突或根变化均未验证；忽略数据、错误中心/偏移、动态文字溢出仍失败。未选根保留窗口坐标契约，错误同时提示坐标域与可用输入，不自动选择 renderer。
- [x] 现有 measure 帮助/能力事实支持新字段，无新职责/Review prompt。字体驱动明确报不支持此几何选项；像素/音频 schema 不接受它。UI 检查提升至 v3-ui-dom-consumption.4，不改旧回执或自动执行。
- [x] 字段经正常 measurement schema → 实际合成源码构建 → smoke → UI 因果检查 → handoff → 可编辑工程导出完整保留；没有生成 BGS Task/固定阶段，quality 仍为 unverified、deliveryEligible=false。
