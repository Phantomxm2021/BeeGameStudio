## 1. 情绪与视觉核心

- **情绪定位**：轻快、俏皮、街机感；像一台温柔的现代街机——干净、圆润、有一点糖果质感，但不幼稚、不繁复。
- **视觉母题（motif）**：圆润的胶囊蛇身 + 一颗发光的“果实”。蛇是有表情的主角，食物是带微光晕的果实；标题画面以“盘成螺旋的蛇围着一颗果实”为主图，一眼传达玩法。
- **焦点层级**：蛇头 > 食物 > 蛇身 > 棋盘 > 背景。任何画面中蛇头的明度/饱和度对比最高。

## 2. 形状语言（Shape language）

- 全局采用**大圆角、饱满、无锐角**的形状语言：蛇身为连续胶囊（圆角半径≈身宽 50%），食物为圆形/微椭圆果实，棋盘格为圆角方块（圆角 4–6 du），按钮为大圆角胶囊。
- 蛇头比身体节略大（约 110%）并带两个圆形眼睛 + 小瞳孔，瞳孔朝当前前进方向偏移，提供“蛇要往哪走”的非颜色线索。
- 蛇尾末端渐细（最后一节 80% 宽）以明确头尾方向；吃食物时蛇头有一个 100–150ms 的轻微“张嘴/挤压”形变。
- 危险与安全不靠颜色单独传达：蛇头眼睛方向、蛇身连续性、棋盘实体边框共同承担信息（见第 6 章）。

## 3. 调色板（Paletted，可直接用于资产生成约束）

| 角色 | 色值（参考） | 用途 |
|---|---|---|
| 蛇身主色 | #4CAF50（中绿） | 身体填充 |
| 蛇头强调 | #2E7D32（深绿） | 蛇头/瞳孔描边 |
| 蛇腹高光 | #A5D6A7（浅绿） | 每节顶部 1/3 高光，增体积 |
| 食物 | #FF5252（珊瑚红） | 果实主体 |
| 食物高光 | #FF8A80 | 果实亮斑与外发光 |
| 棋盘格 A/B | #1F2937 / #24303F | 深色双色格，极低对比差 |
| 棋盘边框 | #0F172A | 实体封闭边框，明确“撞墙”边界 |
| 背景 | #111827 → #0B1020 渐变 | 棋盘外安静区 |
| UI 主文字 | #F9FAFB | 分数/标题 |
| UI 强调 | #FBBF24（暖黄） | 按钮、最高分 |

- 深色棋盘 + 高饱和绿蛇 + 红色果实构成经典互补对比；棋盘 A/B 格色差刻意压小，只作网格提示，不与蛇/食物争夺注意。
- 色觉友好：红/绿同时出现时，食物靠**圆形+脉冲光晕**、蛇靠**胶囊连续形+眼睛**区分，色盲玩家可辨。

## 4. 材质、光感与细节密度

- 表面为柔和哑光糖果质感：低强度顶部高光、无写实物理反射；食物带自发光（外发光半径约果实半径 30%），是棋盘上唯一自发光体。
- 无写实纹理；细节密度低——纯色块 + 一个高光层 + 统一 1–2du 内描边。生成/检索资产必须遵守“每主体 ≤ 2 层细节”。
- 光照是平的、氛围性的，不产生影响判定的阴影；蛇身下方可有极淡接触阴影（透明度 ≤ 15%）增强贴盘感。

## 5. 屏幕与画面构成（玩家可见界面的视觉身份）

- **标题/就绪屏**：居中“螺旋盘蛇绕果实”主图；标题“贪吃蛇”使用圆润粗体中文（字重 800，圆角感字体族），字底无复杂特效，主图承担视觉冲击；下方留出大面积安静区放开始按钮（几何归 UI_UX）。
- **游玩屏**：棋盘占视觉中心，HUD 为小尺寸高对比数字（当前分白色、最高分暖黄），不发光、不抢焦；棋盘外背景是低明度渐变安静区。
- **暂停屏**：棋盘压暗（叠加 40–50% 透明深色）+ 中央简洁暂停符号，营造“时间冻结”。
- **失败结算**：棋盘短暂去饱和（0.3s 内）后弹出结算卡；红色仅用于“失败”标签而非全屏红光，避免刺眼。
- **通关结算**：果实金色脉冲 + 蛇身轻微弹跳，暖黄主导，奖励感。
- 转场情绪：所有状态切换使用 150–250ms 快速淡入/轻微缩放，不使用长动画；重开立即复位，无加载页（本地数据）。

## 6. 可读性规则（在实际显示尺度上）

- 蛇头：深绿+眼睛+略大尺寸，三重区分；眼睛瞳孔方向是转向的即时反馈。
- 食物：红色圆形 + 呼吸脉冲（缩放 100%↔108%，约 600ms 周期）+ 外发光，在深色棋盘上任何位置都一眼可见。`prefers-reduced-motion` 下停止脉冲缩放，保留圆形与外发光（识别不依赖运动）。
- 危险（边界）：棋盘四周连续不透明深色粗边框（视觉宽度 ≥ 6du），与背景明度拉开，明确封闭性。
- 状态变化：进食=蛇头形变+食物消失迸出 4–6 个小亮点（120ms）；加速无强制特效（避免高速时干扰），可选一次极淡的节拍闪光；死亡=蛇头红色闪烁 2 次后去饱和。
- 不允许用闪烁红光、高速频闪表达关键信息（无障碍）。

## 7. 分层与合成

| 层 | 内容 | 合成要点 |
|---|---|---|
| 背景层 | 深色渐变 + 可选极淡网格点装饰 | 静止，棋盘外留白区适用；不随容器平移 |
| 棋盘层 | A/B 格底纹 + 实体边框 | 整盘一个纹理/绘制单元，支持等比缩放 |
| 主体层 | 食物、蛇身、蛇头 | 蛇按节绘制于统一容器；食物独立节点；接触阴影随主体 |
| 反馈/特效层 | 进食迸点、结算脉冲、暂停压暗 | 透明层，独立于逻辑，120–300ms 短生命周期 |
| UI 层 | HUD、按钮、结算卡 | 视觉语言（圆角、黄/白/深色）与世界一致；几何由 UI_UX 数据驱动 |

- 棋盘层需支持整体等比缩放与各向同性；背景层需独立于棋盘覆盖任意宽高比（宽屏左右、竖屏上下延展），因此背景为可平铺/渐变而非固定大图。
- 响应式下颜色、描边相对比例保持；缩放后 1–2du 细描边若小于 1 物理像素允许按最小 1px 呈现，但不得加粗到改变格位感。

## 8. 资产一致性标准（生成/检索/程序化通用）

1. 圆角饱满、无锐角；哑光糖果质感、无写实纹理、无硬描边线稿风。
2. 严格使用第 3 章色板；新增颜色须先入表。
3. 每个主体 ≤ 2 层细节 + 单一顶部高光方向（光源统一在上方）。
4. 蛇家族保持统一身宽、胶囊圆角与节间距（节间距 0，描边内缩）；食物家族保持圆形与发光。
5. 不同来源资产需通过以上 4 条比对；风格不符或体积过大的资产不予采用（首版资产体积极小，应以矢量/形状绘制为主，不引入需要下载的位图套图，最终清单由 ASSET_PLAN 决定）。
