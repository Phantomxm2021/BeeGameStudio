1. **检查适用性／定位不完善**：每个 UI 探针都要求位置＋尺寸扰动且必须有显式 layout.size。正常 flex／拉伸节点因不支持其中一项被整体排除；聚合错误不带失败文件／节点，作者先查源、后逐条试探，最终缩到两个容器。两个早期结果还继承 smoke 文件覆盖，不能把文件列表当实际 UI 覆盖。
2. **验收任务选择和判断**：作者将广义品质核对变成旧 PASS 证据复用＋局部几何校验；子任务继续围绕作者列出的事实展开。本轮未见 BGS 改写／丢失该子任务；不足不能全推给系统桥接，更不能追加 Review prompt 宣称解决。
3. **宿主响应异常**：PID3574 仍监听，运行服务健康超时、单核100%；相邻 billing 健康200。采样显示主线程繁忙，但 JIT 未符号化，**尚未定位具体热函数**。stdout 转发出现94–96秒间隔，主查询等待并两次 TaskOutput。最终自然完成、健康200／CPU0.1%。正常暂停按钮的一次点击尝试超时，未确认送达，最终没有 paused 或 interrupted 状态；没有杀进程／重启／收费续作。
