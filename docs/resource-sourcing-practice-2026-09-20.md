# 资源获取：现成资源优先，缺口再生成

本文件替代已删除的、依赖 Game IR 的旧资源生产计划。适用于所有项目，不针对单个测试案例。

## 目标与边界

八文档 → 资源 Agent 自主获取/必要时制作 → Asset Manifest → Scene/UI/VFX Content → 目标实现。

图像资源按“内建库 → 互联网检索 → AI 生图 → 程序绘制”的来源优先级获取。上一来源不能满足用途、风格、格式或授权条件，才考虑下一来源；查询词、站点、工具及合理检索深度由 Agent 决定，不要求固定调用次数。已有资源可复用，但既有自制文件不豁免来源要求。Agent 编写的“自绘为主”不是用户允许跳过来源的授权；只有明确用户要求可以覆盖这项优先级。文字/布局、程序化特效及音频等使用适用能力，不机械调用图片 API。

不增加代理、模型调用、采购状态机或自动重试。工具入口帮助 Agent 获取资源，不替它选择素材。Manifest 仍是唯一运行资源清单。

## 已落地的能力

- RESOURCE_PREPARATION 获得临时本机只读资源接口，可直接使用原生 Bash/curl 查资源包、元素及下载地址；不依赖 SearchExtraTools 能否发现资源库工具。
- 接口复用现有资源服务和当前用户的可刷新登录凭据。凭据留在宿主；临时随机地址只允许读资源，不允许修改、上传、管理或转发任意 URL。任务停止/关闭/正常收尾后关闭。
- 获取实际文件时检查包版本、许可证与依赖，不把封面当作运行资产；记录实际来源、文件及 hash。互联网继续使用原生搜索/浏览器/HTTP 工具，不改 Agent 内核。
- 未配置、认证失败、服务不可达须如实报告，不伪装成空搜索。查不到资源库工具不能作为跳过互联网的理由。
- 按现有 source/selection_reason 记录实际检查过的来源及不适用原因，不新增采购报告协议；不得虚构检索、许可证或“没有合适素材”结论。

## 交付判断

接口通过不代表美术/音频质量通过。实际文件必须满足已接受文档；provisional 合成配方不能无说明地替代要求的音频文件。资源 Agent 自主检查所选素材；宿主只负责现有文件/绑定/版本边界，不新增审美审核代理。

AI 图片接口、独立 provider 配置及图片计费已实现，资源 Worker 按实际配置获得访问能力；见 image-generation-provider-implementation-2026-09-20.md。图片生成不能替代音频、模型等资源的具体规范。

## 联网配置与检索证据

- BGS 将用户 Web Search/Web Fetch 配置完整写入该用户私有的原生运行配置：搜索/抓取 adapter、服务地址、密钥及抓取超时。原生工具继续负责执行；不新增搜索代理或自定义搜索链。配置读取失败不伪装成“没有搜索结果”。
- 复用以前自制的文件，不等于已满足来源优先级。Agent 应按图像资源组在现有 selection_reason 中记录实际查询、候选页面、检索日期与不适用/访问失败原因，可引用组内共用证据；实际采用的网络资源在 source 中记录来源与许可证。只有用户明确限定原创方式才覆盖来源顺序，不能把 Agent 自写的美术描述当作例外。

## 生图失败与本轮交付边界

### 生图 Prompt 记录

实际调用生图入口时，由生图模块自动维护 `assets/ai-generation-prompts.md`；未调用则不创建空报告。删除 Agent 手工维护要求，不新增阶段、审核、代理或工具回填接口。

- 请求到达后、调用生成服务前记录实际 prompt、requestId、background 及宿主当前 provider/model/size/quality；配置读取失败时配置标记 unknown。记录表示“入口收到请求”，不虚称已提交上游。
- 返回后自动补充 image-returned 或安全的失败诊断；同一 requestId 的重放/恢复追加在同一记录下，不重复登记为新生成。第一次观察到的输入保留，历史缺失不补造。
- 只白名单记录所需配置；不写密钥、临时能力接口地址、签名下载 URL、账单或原始上游错误。prompt 正文中的上述敏感内容也会脱敏。
- 最终文件路径、加工关系、来源和运行绑定只归 Manifest，记录文档不维护第二份资源事实。它不是生成计划：编辑它不会触发生成，计费/恢复/资源加载均不读取它。
- 记录失败会写宿主警告，并通过响应头或错误 JSON 明示；不丢弃已付费结果、不因此重试。项目符号链接不能把记录写到项目外。

临时生图入口返回安全结构化错误（stage、code、upstreamStatus、diagnosticId、replayed），不输出密钥或原始上游正文。上游响应正文只在宿主脱敏日志中保留。Cloudflare 原生 /ai/run 协议与 OpenAI-compatible images/generations 不能混用；已知不匹配在提交前报 protocol-config-mismatch，不自动切协议或重试。

失败收据保留诊断 ID、状态和分类；同 requestId 返回已有失败时标注 replayed，不能说成再次请求上游失败。unknown 保留防重复付费语义，不删除收据来强制重试。Agent 使用 --fail-with-body 读取错误 JSON，不能把它当 PNG 注册。AI 失败不豁免遗漏的网络检索，也不允许以不合格几何占位图偷偷降级交付。

## 验证与当前限制

本批定向测试覆盖只读接口、用户凭据刷新、下载地址返回、禁写/禁跨源调用、访问失败不是空结果、关闭回收，以及既有 worker 回归。它们不证明真实库已含适合某个项目的素材。

尚需部署后在真实登录项目验证：查询内建库 → 选取合适资源并下载 → Manifest 注册，以及针对素材缺口的实际网络获取。未执行前不声称线上链路已验收，也不重置或重跑已有项目。
