# Reviewer 连续会话与收敛调整

本次只修改实现并进行离线验证。没有恢复真实审计、调用付费模型、修改八份审计输入、重算历史账单或重启运行服务。

## 改动

- 一个持续运行的原生 CLI 进程完成同一次审计。首轮包含全部编号原文；后续只发送最新宿主反馈，保留原生会话中的文本和动作上下文。
- 每个 terminal 封存本轮动作和用量，宿主结算、验收并执行只读工具后才发送下一轮。原生累计用量按前后差额入账；中断时使用本轮已观察到的消息快照，不重复计入前轮。累计计数异常倒退时失败关闭，不猜测。
- 日志沿用 closed 事件名以兼容旧记录，但新增 sealScope=native-turn 明确它只代表回合封存，不代表子进程退出。任务退出时等待所拥有的直接子进程关闭；不会据此声称清理了整个进程树。
- 所有输入逐行标明位置和总行数。read 明示最多 200 行及实际边界；错误反馈带具体限制，不再只有通用失败提示。已提供的原文无需为抄引文再次读取。
- 模型接口只提交引用文件和起止行号，由宿主从不可变输入复制原文。内部报告及旧日志仍保留严格的原文字节校验，不能用局部引文或错误行号绕过校验。选中行是否支持论点仍是审计语义责任。
- 引用不匹配一次列出全部位置。amend_draft 绑定报告摘要，只替换指定引用；confirm_draft 绑定已验收草稿并提交最终遗漏检查，不必重新生成全部发现。实质性内容变化仍应提交新草稿。
- 累计限制：12 个宿主动作、12 分钟活动执行时间、400,000 个观察到的 token（含缓存）。观察到超限即停止；停止/继续不清零。连续两轮只重复更早请求过的读取或计算会停止。预算耗尽仍允许重试未完成的结算，但不能继续生成。

## 验证与边界

原生编译 CLI + 本机假模型验证三轮同 PID、原始输入只注入一次、前轮普通文本与结构化动作仍在后续上下文、暂停期间没有自主发起下一次模型请求、三轮差额计量，以及第三轮中断后只计本轮快照。测试结束验证直接子进程已退出。

合并离线回归为 72 项通过、0 失败（16 文件、511 断言），覆盖审计测试及 Author → Reviewer → Revision → Reviewer、跨文档证据交接、公开认证和结算边界。仓库及服务端类型检查通过。

对本次真实失败记录进行了只读机械回放：14 条发现、26 处引用，全部 17 处不匹配一次被列出；局部引用补丁可验收。回放保留原报告选定的位置，不证明这些位置在语义上支持结论，也没有发布回放结果。

原始模型文本只在活动原生会话中保留，不新增落盘日志。显式停止或服务重启后会话会结束；后续恢复从完整源文件和已封存动作重建，不能恢复未持久化的推理。旧日志没有活动时长字段时不臆造历史耗时，其既有 token 与动作数量仍纳入限制。

上述预算是当前保守运行边界，不是已验证的内容质量或耗时承诺。真实完整审计的质量、召回率和实际收敛速度仍未验收；当前真实项目继续保持停止。
