## 字体审计结论（只读样本：bomb-rogue-arena）

- Manifest 称 Fusion Pixel 子集“逐字校验无缺字”；实际 WOFF2 的 cmap 有 190 个字形。六份 UI JSON 的 68 处静态文本中，**43 处含缺字，共缺 54 种字符**。这是可复现的错误声明；浏览器可能用系统字体回退，不能仅凭静态检查断言屏幕上完全不显示。
- 六份 UI 文档仅两份显式引用该字体。UI Editor 按 `data.font.assetRef` 加载；样本 Runtime 则写死 `'Fusion Pixel'` 并通过 CSS 加载文件。两者不是同一数据来源。
- 本轮未检查动态文案、所有语言、实际手机可读性或许可证真伪；没有改样本项目。

字体审计只证明上述事实。修复重点是**让资源声明、UI 数据和运行时实际用字一致**，不是让 BGS 规定游戏必须采用哪款字体。
