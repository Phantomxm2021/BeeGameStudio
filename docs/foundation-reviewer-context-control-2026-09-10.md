# 固定实现后的上下文对照

不修改 Reviewer、模型配置或设计文档。一次实验含两个独立原生模型会话，使用同一 ark-code-latest 配置、相同提示与输出结构、相同非数值审查范围：链接、权威归属、公式 ID、语义范围。一组输入原八文档全文，另一组输入保持原始路径和行号的选定片段；两组都保留原需求。

片段保留既有三项漏报及对应权威上下文，并包括正常引用、表现/模拟分层、maturity/status 等反例。评分答案不传入模型。已看过历史结果，因此不是盲测。原文片段经过选择，除长度外也改变相关信息密度；本实验只能识别上下文集中后表现是否改善，不能单独证明长上下文是唯一原因。

固定评分：GDD85 波次归属、BALANCE111 F_LEAF、ASSET72 错链；反例检查 maturity/status 混淆、表现音频随机、画布/应用面、视觉/模拟弹道。其他已知真实问题分别记录。使用窄审查任务以排除算术工具差异，不与前次完整 Reviewer 的总分直接比较。

两组均按实际用量计费，最多各一次执行；无自动重跑、无 Revision。运行结果和用量保存在隔离临时目录，最后将事实与结论补充到本文档。
