# Reviewer 升级（2026-09-09）

## 范围

只修改 Foundation Reviewer 及其离线测试。未修改 Author、Revision、DSL、用户八文档；未重启服务、部署或调用付费模型。已有改动保留。

## 已实现

1. 为原有十项专项检查补齐跨文档场景证据：波次/生成与数值、恢复与输入、胜负与验收、即时伤害与声画/资产、几何与视觉约束等。八文档的每个 canonical block（包括摘要和生产图表）至少进入一个专项包，并由独立覆盖测试约束。仍按每项明确的 objective 审查，并非把所有文档重复发送给每个检查。
2. 增加服务端纯计算证据：折线路径和射程圆交集 → 生成偏移后的射程时间窗口并集 → 冷却约束下最大射击数 → 初始塔伤害上界及下一座塔的赏金门槛。证据、版本和输入被绑定到不可变 semantic packet；原审查与独立强复核都收到相同计算证据。
3. targeted `round_complete` 不再直接发布最终 PASS；同一 Reviewer 所有者使用完整候选文档重新运行格式、事实、确定性规则和十项专项检查。原 targeted FAIL 仍按同轮重试处理。完整复核新发现的问题进入最终 issues，使用独立身份，不能被原局部 PASS 抹去。
4. 完整复核有持久化 journal、执行租约、停止/恢复及独立用量凭证；未完成时不发布候选 PASS。getResult 保持只读；已完成的局部凭证在恢复时不重跑，丢失发布标记只由显式 resume 修复。迟到 stop 不撤销已发布结果。

## 数值能力边界

计算内核支持任意有限二维折线、点位、正射程/速度/冷却以及有界生成时刻。当前文本适配器仅支持明确的 P0…Pn / S1…Sn Mermaid 单向链、指定参数表字段及单位、单一敌人类型的显式 W1 生成表；不支持的格式、分支路径、混合首波、歧义单位和重复输入返回 `unsupported`，不伪造结果。

计算结果是**有条件的乐观上界**。单目标、固定伤害、不可出售/升级、无其他收入等条件仍须由语义审查对照文档验证；字段 `verified: false` 明确表示尚未验证这些语义前提。上界足够大不证明存在可行策略。当前不是通用游戏仿真、自动 SVG 坐标/遮挡审计，也不是所有类型游戏的数学正确性保证。

使用现有最终塔防文档的原始 canonical section 做只读适配验证，得到每点射击上界 `[26,26,18,26,20,18,20,26]`，三塔伤害上界 780，获得第四塔所需击杀伤害 840，与此前独立复算一致。用户文档未被改写。

## 验证与费用

- 保留既有测试断言强度；新增跨文档新问题拦截、完整复核中停止/恢复、晚到停止、几何/时间窗口/边界、参数扰动、歧义输入拒绝、生产 packet 绑定等回归。
- 本次所有执行测试使用离线协议进程；它们验证调度、证据、状态与费用去重，不验证真实模型发现问题的能力。
- 一次局部语义检查且无需提取事实的测试，现在对应 1 次局部 + 10 次完整专项 = 11 份真实离线 dispatch 账单回执；恢复/补发布不得多记。生产的完整事实提取与必要强复核会另有实际调用，不能以 11 作为固定生产成本。
- semantic policy 升为 v5。现有旧策略 journal 不会被自动迁移或冒充新策略审查；部署/新请求验收需另行执行。
