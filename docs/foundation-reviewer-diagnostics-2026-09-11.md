## 诊断记录

Reviewer 原生执行目录中新增 `diagnostics-<uuid>.jsonl`，与原 journal 分开，文件权限 0600。记录包括：

- 宿主创建进程、发送输入、首次 stdout、停止请求及进程退出；
- CLI 入口、headless 就绪、客户端创建；
- 请求序号、发出时间、响应头状态、首条流事件、流结束；
- API 错误类别、HTTP 状态、尝试次数和退避时长；
- 首次模型消息、首次用量、turn 结果；
- stderr 字节/行数及固定错误类别。

不保存原始 stderr、密钥、Authorization、完整 URL、请求体、提示词、模型内容或任意错误文本。宿主独立按白名单解析子进程元数据，不引入对 CLI 实现或其他 stage 的依赖。原 journal 仍是报告准入和记账依据，诊断日志不获得这些权限。
