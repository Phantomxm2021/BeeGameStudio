## 1. 目标与非目标

目标是让一个审查 Agent 阅读原始需求和完整八文档，理解整套游戏，发现有实际依据的问题，区分合理分工、不同范围与例外，准确报告证据和影响。程序负责可信输入、工具边界、引用绑定、预算、停止、计费与发布；不把机械校验通过包装成语义正确。

完成不等于某次命中几道已知题。必须同时满足：明确缺陷检出、正常样本不误报、报告不歪曲原文、计算声明真实、流程可完成、成本可解释。

保持当前单 Agent、全文/必要时完整分段读取、read/calculate、可选 draft 与直接 final。暂不新增事实提取阶段、审查代理、覆盖矩阵、证明语言、强制二次复核或语义状态机。不为通过验收提高时间/动作上限。不得修改真实八文档来迎合评分。

本轮范围仅 Reviewer。Revision 交接、Checklist、Game IR、游戏代码与发布均不进入。本地登录/服务恢复只作为测试基础设施维护，不新增产品 UI。

## 3. 验收基准先于改代码

### 3.1 分三类记分

**确定缺陷**：现有七个原文锚点——bp_03 距离标注、cue 计数、ART UI 链接、GDD 数值权威链接、GDD 波次归属、F_LEAF、ASSET 美术验收链接。UI 波次来源、ART 波间窗口归属作为扩展锚点另列，不能悄悄改变历史分母。

**正常/范围对照**：链接标签与 href 分离、文档图板与应用面分离、模拟与表现层分离、maturity 与 status 分离。每类设计一对只改变关键语义的正反例，例如“图板含标题”与“实际应用尺寸冲突”。只有原文明确同一对象/范围时才能标为确定矛盾。

**有歧义的材料**：现有弹道、音频随机、混合图示问题单列。接受有依据的保留意见，不强制模型输出固定结论；但不接受擅自补出模拟前提、外推禁令或不受证据支持的改法。

### 3.2 数据分组

- 开发回归组：现有已知八文档与已定位问题，公开承认它不是盲测。
- 最小对照组：至少覆盖引用身份、权威归属、作用域、数值依据、正常例外；按正反例成对，使用新名称和数值，避免仅记住旧答案。
- 保留组：在修改候选之前冻结，不用于提示词迭代；至少包括一份正常小型八文档集和一份带明确缺陷的八文档集。它是内部保留样本，不宣称第三方盲评或行业代表性。

基准与评分说明只在测试侧，绝不注入生产审查提示。不能仅让另一个 LLM 决定真值。每项结论要能回到原文；争议项从硬性正确率中剥离。

### 3.3 统一记分表

每次记录：确定缺陷命中/漏报、确定误报、报告自身失真、无依据影响或修复建议、工具声明真实性、范围执行情况、完成状态、原生动作/工具次数、耗时、tokens、credits。

“发现数”“completed”“引用有效”“自称已全文复查”都不能单独成为通过标准。合并同根因问题按实际覆盖位置评分，不按标题数量评分。

## 4. 执行阶段及决策门槛

### P0：冻结并核验基线（已落盘，零付费调用）

1. 固定实际工作树、当前源文件摘要、模型配置 ID、原始输入摘要；保留全部现有改动，不新拉 worktree、不混入其他任务修改。
2. 整理上述原始实测，建立一张统一记分表；区分完整公开 Reviewer 实测、隔离任务对照、新会话复核，不能混成同一种验收。
3. 运行现有 Reviewer 离线回归，确认输入、工具、引用、预算、计费、重放、发布边界仍然工作。
4. 建立并复核最小对照组与保留组。先核验测试本身，后运行模型。

**退出条件**：可从一条固定命令得到同一输入和同一评分报告；基准的正反例有可解释的原文依据。发现输入/映射/工具的确定代码缺陷则先单独修复并回归，不与语义实验混改。

### P1：验证当前模型的基础判断（小输入筛查）

使用当前模型、当前完整审查语义范围和当前报告结构，给足判定所需上下文，检查最小正反例。先运行两次新的独立会话，不能用旧报告引导。

- 若简单引用身份/明确作用域在两次中持续出错，先调查基础判断能力或提示/输出契约冲突，不增加全流程步骤。
- 若小样本稳定而整套文档不稳定，再进入 P2 的任务/输出负担对照。
- 若两次波动明显且不足以区分原因，记为不确定；最多补一对事先明确用途的对照，不无限重复到碰巧通过。

本阶段最多四次小输入会话。若要比较其他模型，只使用已核实的可用配置并单独控制模型变量；新增供应商/数据目的地或变更产品模型设置不包含在本计划自动实施范围内。

### P2：只验证一个最有证据的候选

优先调查“报告表达负担”：固定完整审查范围、同一全文、同一模型与工具，比较现有报告结构与简化的诊断输出，判断错误是否在扩写 actual/impact/repair 等字段时增加。该简化结构仅存在于实验侧，不提前迁移业务 schema。

如果 P1 已发现更明确的实现原因，则以该原因替代此实验，先在计划记录变更理由。不能同时保留多个候选并不断换方向。
