# Credits 与生图计费口径

2026-09-27 修订。统一 Credits 面值与商店发放量；模型消费另计服务价格。

**1 Credit 的购买面值为 $0.01；$1 购买 100 Credits。** Credits 不是可提现的美元余额。模型消耗不按上游成本原价转扣，而按已公开的模型价格倍率计价。

四档均按同一面值发放；目前不设大额购买赠送 Credits。Stripe Price 保持现价；BGS 发放量由商店套餐配置决定。新结账会话记录当时的发放量；支付回调使用该快照，调价前已打开的结账会话与已完成购买的账本均不追溯修改。

## 生图扣费

- 管理后台针对具体生图模型配置五类美元单价（每百万 tokens）：文本输入、缓存文本输入、图片输入、缓存图片输入、图片输出。当前 GPT Image 2.5 Flare 参考价分别为 $5、$1.25、$8、$3、$30；价格应可调整，不写入文字模型的 Credits 权重。
- 只使用供应商返回的可信、可按类别拆分的实际 token 用量。上游美元成本为各类 tokens × 对应美元单价 ÷ 1,000,000；**钱包扣费 = 上游美元成本 × 1.5（模型价格倍率）× 100 Credits/USD**，最终在钱包边界取整到 micro-Credits。例：上游成本 $1，用户消费 150 Credits。1.5 倍是对上游成本加价 50%，并非 50% 毛利率。缓存 token 不得再按普通输入重复计费。
- 倍率由管理员配置，当前批准值为 1.5。价格变更仅影响新请求；已预留请求按当时的价格快照结算。成功的交付只扣一次，确定失败释放预留，结果未知不自动重试或猜测扣费。
- Cloudflare `/ai/run` 当前不返回可结算的单次 token 用量，故明确使用**独立的固定售价**，绝不假称按 token 结算。管理员在生图设置中按质量 × 尺寸配置 Credits／张。生成前展示售价并预留同额，图片成功保存后按预留价格结算；确定失败释放预留，结果未知保留预留供核对。同一请求恢复不重复向上游生图。历史待结算请求不按新价格追溯扣款。

| Cloudflare 初始售价 | 1024×1024 | 1024×1536 | 1536×1024 |
| --- | ---: | ---: | ---: |
| low | 3 Credits | 4 Credits | 4 Credits |
| medium | 8 Credits | 10 Credits | 10 Credits |

未配置售价的质量／尺寸不能生成；目前 `auto`、`high`、`xhigh`、`max` 均未开放。使用参考图编辑沿用对应质量／尺寸售价。固定售价是 BGS 向用户收取的价格，不代表 Cloudflare 单次实际成本。

## 供应商与计费兼容性（2026-10-24）

| 来源与供应商 | 当前结算规则 |
| --- | --- |
| 平台 Cloudflare、管理员共享 ChatGPT 订阅 | 必须配置质量 × 尺寸固定售价；按请求预留时冻结的价格结算。 |
| 平台 OpenAI、Vercel Images 协议 | 仅完整、相互一致的输入与输出 token 类别明细可按配置费率结算。供应商或模型名称本身不保证响应具备这些字段。 |
| 平台 OpenRouter | 当前汇总用量缺少本系统费率所需的类别明细，新请求不开放；能力查询返回不可用及原因，提交在钱包预留和供应商调用前返回 `422 / billing-unsupported`。 |
| 用户自带 API Key（含 OpenRouter）、个人 ChatGPT 订阅 | 分别由外部供应商、个人订阅计费，不换算为平台 Credits；沿用各自配置与调用限制。 |

[OpenRouter 图片接口](https://openrouter.ai/docs/api/api-reference/images/generate-an-image)的汇总 token 数和 `usage.cost` 不能替代当前按类别单价计算的规则；不从总价反推 token，也不套用其他供应商的固定售价。[OpenAI Images 接口](https://developers.openai.com/api/reference/resources/images/methods/generate)将 `output_tokens_details` 列为可选，未提供明细时不能据此断言输出全部属于图片；当前解析继续拒绝缺失或含糊的计费数据。Vercel 的具体模型用量兼容性尚未通过真实付费响应验证。

新请求限制复用已有请求校验入口，不改变请求身份。资产命令仅在报价返回明确的 `billing-unsupported` 时继续交给宿主判断：已有收据可恢复，新请求仍在预留前拒绝；其他不可用报价仍直接停止。已有本地图片收据仍按原 requestId 恢复；原始图片、usage 和冻结费率保留，不能结算的旧请求继续待核对，不补造费用、不重复生图。若本地收据已丢失，前置拒绝也不会新增预留或重新生成，已有钱包预留仍需人工核对。

本地模拟验证覆盖不可用查询、直接服务与 HTTP 提交均在预留前拒绝、BYOK 继续由外部计费，以及旧图片重复恢复不新增供应商调用、不猜测扣费。未修改供应商配置、既有项目或账本，未运行真实付费请求。

## 验收

1. 商店四档的美元售价和发放量与表格一致，均为 100 Credits/USD；新旧订单分别按购买时的套餐发放。
2. 模拟含五类 token 的响应，验证上游美元价与模型倍率变动分别改变 Credits 扣费；缺少用量或缓存类别不明确时不得按零或普通输入费率扣款。
3. 账本用同一 requestId 防重复扣费；预留、结算、失败释放保持原子性。真实付费生图须单独授权，不属于本次无费用验收。
4. Cloudflare 六档分别查询报价，并用无 token 的模拟图片验证固定价预留／结算、未定价档位拦截、同 requestId 恢复不重复生成。
