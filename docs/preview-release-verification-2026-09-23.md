# Preview 与发布状态修复记录

日期：2026-09-23。范围仅限 BGS；未修改私有项目源码、资源、Scene/UI JSON 或验收记录。

## 已实施

- 将 HTTP 预览代理从 `app.ts` 移至 `beegame/preview-proxy.ts`，路由仍负责访问控制，代理只负责转发与传输生命周期。
- 上游响应等待/无数据传输超过 15 秒终止；连续传输按数据进展续期，取消标签页或响应流会取消对应上游请求，不停止项目进程。去除逐跳 HTTP 头，保持 query、压缩、HEAD 和缓存语义。
- 预览启动探测逐次限时并释放响应体，只接受成功响应，不把 404 当作就绪。
- 已有效授权的预览沿用原有 session capability/子资源验证，不为每个模块再次请求认证上游；无授权访问仍需认证。未扩大原有子资源访问策略。
- 修正 iframe 错误通知的父窗口目标：隔离沙箱与 no-referrer 下不能根据 referrer 推导宿主地址。宿主验证来源窗口及 session。
- 前端等待文档及入口模块载入消息，脚本失败、加载超时显示可重载的错误；HTTP 错误页的 iframe.onload 不算成功。此状态不等于游戏玩法验收通过。
- 发布面板展示后台实际阻塞原因，区分 Chat 任务 PASS 与当前版本发布验收。保留原验收门槛；重新检查只读，不启动 Agent、不自动重跑 workflow。

## 验证

- 后端相关回归：32 项通过，含真实本地 HTTP、Vite TSX/CSS 转译、认证服务不可用、请求取消、闲置传输超时及连续 300 次取消后继续请求。
- 前端相关回归：20 项通过；类型检查通过。当前安装的 TypeScript 6 对原有 baseUrl 发出弃用错误，验证命令使用 `--ignoreDeprecations 6.0`，未改动项目类型配置。
- 浏览器使用独立临时夹具与实际 WorkspacePreviewPanel/代理代码：正常模块显示游戏内容；404 模块与无响应模块显示错误及重载按钮；切回正常模块恢复。不使用私有项目，不产生模型或上传费用。
- 获得用户授权后，使用根目录 `.env.local` 重启 runtime；健康检查通过。临时验收页面及服务已关闭。

- 认证上游本身超时原因仍待定位；本轮解除它与已授权预览子资源的不必要耦合，不宣称修好了外部认证服务或网络。
