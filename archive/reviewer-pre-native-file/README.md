# Reviewer 退役源码归档

2026-09-11：归档旧 host-mediated、native-tools-v2、GDD-led 策略实现及实验脚本，并迁移当前公共入口测试和共享校验测试。

## 归档约定

`sources/` 镜像原仓库相对路径，文件名统一追加 `.txt`。文件内容逐字节保存，没有重写 import、动态路径或历史命令；这些文件是只读参考，不是可运行、可编译或可导入的兼容实现。这样不会让默认测试重新发现旧执行方案，也不会意外启动旧付费评测。

各组 `.manifest.json` 记录原始路径、归档路径、字节长度与 SHA-256。恢复前先核验摘要，再复制指定文件回清单中的原路径；历史 import 与运行环境未保证兼容当前代码，不能直接恢复整个旧执行链。

## 清理与保留

- 活动目录移除 8 个旧策略/工具/trace 模块、3 个专属 fixture、5 个旧执行协议测试文件、16 个旧评测脚本/配置，共 32 个文件。所有原文可恢复。
- 4 个混合测试原位迁移到共享报告、来源及独立审计校验；旧数值/契约测试的共享能力由运行时生成输入的不变量测试覆盖。旧提示词和修改草稿协议不再作为当前验收。
- 新原生文件 schema 使用审阅事实字段 `documentPath`，不再要求或接收旧 `repair` 指令。历史报告的修复字段、策略字面量、摘要、回执及提交标记校验仍保留。
- 旧预算预测/重复轮次辅助函数已无生产调用，原位清理；累计 token/时间统计、显式预算中止及计费保护保留。
- `migration.manifest.json` 还保留了本轮迁移前的预算、当前 fixture 与 schema 原文。这些是迁移记录，不表示相应当前文件已删除。
- 多来源 Reviewer → Revision → Reviewer 公共链路已迁移到真实隔离文件协议，没有增加业务案例或模型预设答案。

没有删除历史付费结果、用户项目文件或凭据，没有启动真实模型、重启运行中的服务或恢复旧策略执行。
