# Bee Game Studio 落地页文案与插图脚本

## 产品核心

Bee Game Studio 让一个只存在于脑海里的游戏想法，变成一款可以亲手玩的游戏。

创作者负责想表达什么、玩家应该感受到什么，以及它最后成为什么。Bee Game Studio 把这些决定，变成一款可以亲自试玩、可以继续打磨的游戏。

对外核心表达：

> 把想法，做成游戏。

## 第三页：一句想法，变成一场游戏

这一页不把制作过程堆成一张说明书，而是做成一个“逐步发生”的舞台：一次只显示一个阶段，自动播放，也可以点击阶段跳转。

固定文案：

> 从一句想法，
> 到一款亲手玩的游戏。

正文：

> 你说出想做什么。然后，看着它一点点成形，直到它真正可以玩起来。

四个阶段：

1. 听懂想法：我想做一款关于深夜便利店的游戏。
2. 找到感觉：雨夜、暖光、沉默的客人，成为这款游戏的感觉。
3. 让场景成形：便利店、角色和选择，逐渐变成你想要的样子。
4. 亲自试玩：现在，你可以亲自玩一遍这段故事。

插图：前三个阶段用简洁的动态画面表现想法、感觉与场景逐步成形；只在“亲自试玩”阶段出现一张雨夜便利店游戏画面，玩家正在面对一个即将展开故事选择的客人。

候选资产：`/images/game/store-choice-v1.png`

## 第四页：最终得到什么

主标题：

> 不只是想象。
> 是一款你可以亲自玩的游戏。

三条结果：

- 第一次试玩，你就知道它是不是你想要的样子。
- 你能把“不对”改成“就是这样”。
- 你能把它交给朋友，看见他们怎么玩。

正文：

> 真正重要的，不是它如何被做出来，而是它有没有变成你愿意分享的那款游戏。

插图策略：不增加插图，让三条结果和判断标准成为视觉焦点。

## 第五页：创作者与 AI 的关系

辅助标题：你始终决定它成为什么

主标题：

> 制作可以交给 AI。  
> 决定始终属于你。

四组内容：

1. 你想留下什么：由你说出来。那是游戏最初的感觉。
2. 玩家感受到什么：由你确认。每一个选择，都更接近你想表达的感觉。
3. 这一版先做到哪里：由你决定。先让最重要的部分发生。
4. 最后它属于谁：始终属于你。这是你做的游戏。

补充文案：

> AI 可以替你完成许多事，但不能替你决定这款游戏应该成为什么。

插图策略：不增加插图，用四组“由你说出来 / 由你确认 / 由你决定 / 始终属于你”建立清晰的控制关系。
