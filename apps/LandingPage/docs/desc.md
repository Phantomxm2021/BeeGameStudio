## 一、官网产品页版

### 关于 Bee Game Studio

Bee Game Studio 是一款面向所有创作者的 AI 游戏创作平台。

无论你是否学习过编程、游戏引擎或美术制作，只要拥有一个游戏想法，就可以从这里开始。告诉 Bee Game Studio 你想创造怎样的世界、玩法和体验，它会帮助你梳理创作方向、完善游戏方案，并逐步完成设计、资源准备、开发、测试与预览。

从“我有一个 idea”，到“这是我做的游戏”，Bee Game Studio 希望让游戏创作不再只属于专业开发者。

### 核心功能

**1. 从一个想法开始**

用自然语言描述你的游戏创意。Bee Game Studio 会围绕玩法、类型、视觉风格、目标平台、操作方式和项目规模，生成多个可选择的创作方向。

**2. 共同完善创作方案**

你可以选择喜欢的方向，调整游戏类型、画面维度、输入方式、美术风格和制作范围。创作方向始终由你决定，AI 负责将想法整理成清晰、可执行的游戏方案。

**3. 完整的游戏制作流程**

平台可围绕已确认的创作方案，协助完成游戏设计文档、技术方案、美术方向、资源准备、关卡内容、程序实现和项目构建。

**4. 实时查看创作进展**

通过项目工作台查看对话记录、制作阶段、资源内容和运行状态，随时了解游戏从创意走向成品的过程。

**5. 可玩预览与持续修改**

生成的不只是概念描述。你可以运行和体验当前版本，并继续用自然语言提出修改意见，让玩法、画面和内容逐步接近心中的样子。

**6. 构建、验证与交付**

Bee Game Studio 通过文档审查、实现审计、构建测试和运行验收，对当前版本进行验证，帮助项目从“能够生成”走向“可以运行、体验和交付”。

### 面向群体

- 有游戏创意但缺少编程、美术或引擎经验的普通创作者
- 希望快速验证玩法的独立开发者和小型团队
- 游戏策划、设计师、美术及内容创作者
- 开展游戏设计、互动媒体或编程教学的教师与学生
- 希望制作品牌互动内容、数字展览和游戏化体验的团队
- 需要快速制作原型、演示版本或小型完整游戏的专业开发者

### 产品亮点

**人人都能开始**  
不必先成为游戏开发者。一个清晰或尚未成形的想法，都可以成为创作起点。

**创作者始终掌握方向**  
Bee Game Studio 不是输入一句话后随机给出结果的“游戏 vending machine”。重要方向由用户选择和确认，AI 负责将其转化为可执行成果。

**覆盖完整创作链路**  
从创意梳理、设计文档、资源与美术，到开发、测试、预览和交付，减少在多种工具和流程之间反复切换。

**结果可运行、可验证**  
平台关注的不只是生成了多少代码和文件，更关注游戏能否真实构建、启动、游玩并满足已确认的创作目标。

**不绑定单一平台或引擎**  
可根据项目需求选择 Web、原生应用、Unity、Godot、XR 等目标环境，适应不同类型的游戏创作。

**可持续迭代**  
创作不是一次性生成。用户可以在已有项目基础上继续沟通、修改和验证，让游戏随想法不断成长。

## 二、商业计划书版

### 项目介绍

Bee Game Studio 是一个以 AI Agent 为核心的游戏创作与交付平台，致力于降低游戏开发的专业门槛和协作成本。

平台以用户确认的游戏创意和制作要求为起点，将传统游戏开发中的策划、技术设计、资源准备、程序实现、质量审查、运行测试和版本交付连接成一套持续、可追踪的生产流程。用户不需要掌握完整的编程、美术及游戏引擎知识，也能够参与并主导游戏创作。

Bee Game Studio 的目标不是简单生成代码，而是帮助用户获得一个符合创作意图、能够运行、可以验证并可持续迭代的游戏项目。

### 主要功能

**创意理解与方向探索**  
用户输入自由形式的游戏想法后，平台生成多个产品方向，涵盖核心玩法、游戏类型、视觉风格、平台、画面维度、输入方式和项目范围。

**结构化需求确认**  
用户选择并调整方案，形成明确的制作简报，为后续设计、开发和验收建立统一的产品目标。

**AI Agent 协同生产**  
根据项目需求组织设计、资源、美术、程序、关卡、测试等专业任务，在清晰边界内完成协作。

**游戏资源与内容管理**  
支持游戏资源的探索、选择、导入和项目集成，并通过项目工作台管理资源、内容和版本状态。

**开发过程可视化**  
通过项目面板呈现会话、任务阶段、运行记录、资源状态、使用量和预览结果，提高复杂 AI 生产过程的透明度。

**预览、测试与验收**  
对项目执行构建、测试和真实运行验证，并通过独立审查机制检查文档、实现、资源和玩家体验之间的一致性。

**项目恢复与持续迭代**  
制作过程以持久化工作流管理，可在暂停、失败或服务恢复后继续推进，并针对新的用户需求更新对应设计和实现。

**多平台交付能力**  
采用引擎中立的工作方式，可面向 Web、Unity、Godot、原生应用、XR 等不同目标环境开展项目制作。

### 目标用户

**大众创作者**  
拥有游戏创意，但缺少开发团队或专业技能的个人用户。

**独立开发者与小型团队**  
需要降低前期验证成本、缩短原型制作周期并补充专业能力的开发者。

**游戏及互动内容从业者**  
包括策划、设计师、美术、编剧、主播及其他希望将内容转化为互动体验的创作者。

**教育市场**  
面向游戏设计、数字媒体、创意编程和人工智能课程中的教师、学生及培训机构。

**企业与品牌客户**  
适用于品牌互动营销、数字展览、活动体验、内部培训及游戏化内容制作。

**专业研发团队**  
可用于创意验证、垂直切片、内部原型和重复性生产环节，提高团队研发效率。

### 核心亮点与竞争价值

**降低综合创作门槛**  
将自然语言创意转化为结构化生产任务，让非技术用户也能参与游戏开发。

**贯通从创意到交付的流程**  
区别于单点代码生成或素材生成工具，Bee Game Studio 覆盖设计、资源、实现、验证和交付环节。

**坚持 Human-in-the-loop 创作模式**  
关键产品方向由用户明确选择，AI 不替代创作者做未经确认的核心决定。

**建立可验证的交付机制**  
平台依据当前版本的构建、测试、运行和审查证据判断完成状态，降低“代码已生成但项目不可用”的风险。

**具备平台与引擎扩展性**  
产品不绑定某一种游戏引擎，可根据不同用户和项目需求扩展目标平台、工具与专业能力。

**兼顾个人创作与团队生产**  
既能为个人提供低门槛入口，也能为专业团队提供过程管理、权限、资源和质量验证能力。

### 商业价值

Bee Game Studio 将游戏生产能力从少数专业团队扩展到更广泛的创作者群体，同时帮助现有开发团队减少原型验证和协作成本。其商业价值主要来自创作者订阅、项目制作额度、专业功能、团队协作服务、资源生态及企业级部署等方向。

随着生成式 AI 从内容生成进一步进入复杂项目生产，Bee Game Studio 有机会成为连接“创意表达”与“可交付游戏产品”的基础平台。

## 三、对外宣传版

### Bee Game Studio：让每个人都能创造自己的游戏

每个人心里，都可能有一个想玩的游戏。

它也许来自一次突发奇想、一段睡前故事，或者朋友之间的一句“如果真有这样的游戏就好了”。过去，把这些想法变成真正的游戏，需要学习编程、引擎、美术和复杂的开发流程。Bee Game Studio 希望改变这件事。

Bee Game Studio 是一款 AI 游戏创作平台。用户只需描述自己的想法，就能探索不同的游戏方向，确定玩法、风格、平台和制作范围，并在 AI 的协助下逐步完成设计、资源准备、开发、测试和预览。

它不仅帮助用户“生成一个项目”，还关注游戏是否能够真实运行、是否符合创作目标，以及是否可以继续修改和完善。

### Bee Game Studio 可以做什么？

- 将自然语言创意整理成清晰的游戏方案
- 提供多个可选择、可调整的创作方向
- 协助完成策划、技术、美术、资源和关卡设计
- 推进程序开发、项目构建和运行测试
- 提供游戏预览，让用户直接体验自己的作品
- 根据反馈持续修改和迭代
- 面向不同引擎、平台和交互方式开展创作

### 谁适合使用？

无论你是第一次尝试做游戏的普通玩家，还是独立开发者、设计师、学生、教师、内容创作者或专业团队，只要拥有一个想法，都可以使用 Bee Game Studio 开始创作。

### 为什么是 Bee Game Studio？

因为它希望解决的，不只是“如何更快地生成代码”，而是“如何让一个人的想法真正成为游戏”。

在 Bee Game Studio 中，创作者负责想象、选择和表达，AI 负责理解、执行和验证。双方共同完成从灵感到作品的过程。

**一个想法，就是一款游戏的开始。**  
**Bee Game Studio，让想象成为可以进入、可以游玩、可以分享的世界。**
