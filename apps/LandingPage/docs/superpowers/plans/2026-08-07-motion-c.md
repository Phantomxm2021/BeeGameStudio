# C 方案轻微视差动效实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 Bee Game Studio 落地页中实现克制的轻微视差、一次性滚动揭示和第三页固定画布的共享阶段过渡。

**Architecture:** 页面根节点提供归一化指针变量；`NarrativeSections` 用 `IntersectionObserver` 管理 section 的一次性揭示和第三页可见状态，用 React 状态控制阶段与暂停；CSS 负责所有视觉过渡、层级位移和减少动画降级，不引入动画库。

**Tech Stack:** Vite、React、TypeScript、CSS、Vitest、Testing Library。
